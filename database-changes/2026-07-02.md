## 二、SSO Mock 实现 + 单元测试

### 2.1 SSO Mock 模式

| 文件 | 变更内容 |
|------|---------|
| `backend/apps/accounts/views.py` | `SsoLoginView`：Mock 模式返回可用测试码列表；正式模式重定向 SSO |
| | `SsoCallbackView`：Mock 模式根据 code 查找/创建用户签发 JWT；正式模式返回 501 |
| | 新增 `MOCK_SSO_USERS` 字典：mock_admin / mock_teacher / mock_student |
| | 新增 `_handle_mock_callback()` / `_get_or_create_sso_user()` 方法 |
| `backend/apps/accounts/models.py` | User 模型新增 `sso_uid` 字段（VARCHAR 128, unique, nullable） |
| `backend/apps/accounts/migrations/0003_user_sso_uid.py` | sso_uid 字段 migration |

**Mock 测试码：**

| code | role | 说明 |
|------|------|------|
| `mock_admin` | admin | SSO 管理员 |
| `mock_teacher` | user | SSO 教师 |
| `mock_student` | user | SSO 学生 |

**切换模式**：`.env` 中设 `SSO_MOCK_ENABLED=False` 即切回 501 骨架。

### 2.2 单元测试

| 文件 | 说明 |
|------|------|
| `backend/apps/accounts/tests.py` | 32 个测试用例，4 个测试类 |

| 测试类 | 用例数 | 覆盖范围 |
|------|:--:|------|
| `SsoMockTests` | 14 | SSO GET 测试码列表、POST 回调创建用户、重复回调不重复创建、更新已有用户、JWT 有效性验证、缺少参数、无效 code、空字符串 code、sso_uid 唯一性 |
| `SsoProductionModeTests` | 3 | Mock 关闭后 GET 返回 501 / POST 返回 501 / 配置 SSO URL 后正常返回 |
| `LoginApiTests` | 12 | JWT 登录成功/密码错/用户不存在/缺字段、刷新成功/用 access 刷/无效 token、GET/PUT me、修改密码成功/旧密码错/弱密码/未登录 |
| `EdgeCaseTests` | 3 | 禁用用户不能登录、SSO 用户无本地密码不能 JWT 登录、SSO token 可用 |

```bash
python manage.py test apps.accounts.tests -v 2 --keepdb
```
