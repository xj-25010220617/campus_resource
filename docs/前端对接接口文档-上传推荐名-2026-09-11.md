# 前端对接接口文档 — 上传时标题默认保留原文件名 + 返回 AI「推荐名」（2026-09-11）

> **日期**：2026-09-11
> **后端分支**：main
> **认证说明**：所有接口均需要携带 JWT Token，格式：`Authorization: Bearer <token>`
> **本文档面向**：前端对接同学，说明「上传后标题默认保持原文件名、AI 生成的推荐名如何取用」。

---

## 〇、本次变更清单

| # | 接口 | 变更类型 | 说明 |
|---|------|---------|------|
| 1 | `POST /api/knowledge/upload/file/`（单文件上传） | **返回字段新增** | 新增 `recommended_title`；`title` 改为默认原文件名 |
| 2 | `POST /api/knowledge/upload/batch/`（批量上传） | **返回字段新增** | 每个 success 项新增 `recommended_title`；`title` 改为默认原文件名 |

**请求参数不变**，仅返回行为变化：AI 生成的标题不再自动覆盖原文件名，而是作为「推荐名」单独返回。

---

## 一、问题背景

此前上传文件后，后端会用 AI 从文件内容里生成标题并**直接作为文档标题落库**，用户自己起的原始文件名被覆盖。老师要求：

1. 标题**默认保持原文件的原名**（去扩展名）；
2. AI 生成的名字作为**「推荐名」**在原文件名旁边展示，**供用户选择**。

即：AI 识别结果不再「越俎代庖」覆盖用户原名，只做「推荐」。

---

## 二、新增字段说明

### 2.1 `recommended_title` — AI 推荐名

| 属性 | 值 |
|---|---|
| 类型 | `string` |
| 是否必返 | 是，但**可能为空串 `""`** |
| 含义 | AI 根据文件内容生成的推荐标题 |

**取值规则**：

1. AI 识别成功且返回了标题 → 返回该推荐标题；
2. AI 不可用 / 识别失败 / 空文件 / 解析不到内容 → 返回空串 `""`；
3. 推荐名可能与原文件名相同或相近，前端可自行判断「相同则隐藏」。

### 2.2 `title` — 文档标题（已改语义）

上传成功后落库的 `title` **默认等于原文件名（去扩展名）**，不再等于 AI 生成结果：

| 场景 | `title`（落库） |
|---|---|
| 用户上传时显式传了 `title` | 用用户传的 `title` |
| 用户未传 `title` | 用原文件名去扩展名（如 `热门话题分享.pptx` → `热门话题分享`） |
| 空文件 | `空文件`（维持 2026-09-10 的行为） |

## 四、前端对接建议

**推荐交互**：上传成功后，标题输入框默认填 `title`（原文件名），在其旁边展示一个「推荐名」气泡/标签显示 `recommended_title`，用户可点击「采用推荐名」把 `recommended_title` 填入标题框。

| 场景 | 用哪个字段 |
|---|---|
| 标题输入框默认值 | `title`（已是原文件名） |
| 旁边展示的「推荐名」 | `recommended_title`（为空则隐藏） |
| 用户点击「采用推荐名」 | 调 `PUT /api/knowledge/docs/{id}/`，body `{"title": "<recommended_title>"}` 落库 |
| 用户保持原名 | 什么都不用做（`title` 已是原文件名） |

> 「采用推荐名」复用了既有的文档编辑接口，无需新增接口。

**兜底提示**：

```js
const recommended = resp.recommended_title;
if (recommended && recommended !== resp.title) {
  // 展示「推荐名：xxx」+ 「采用」按钮
} else {
  // AI 未给出可用推荐名，隐藏推荐名区域
}
```

## 五、其他说明

- **描述 / 关键词 / 可见性**：本次只改了「名字」相关行为。`description`、`keywords`、`visibility` 仍由 AI 自动填充落库，未提供时照旧 AI 生成，未改动。
- **文本录入 / 分片上传 / STS 回调**：未改动。文本录入无「原文件名」概念，行为不变；分片上传合并后标题本就默认原文件名。
- **向后兼容**：仅新增返回字段，未删除旧字段；老前端不取 `recommended_title` 也能正常工作，只是拿不到推荐名。
