# FAQ 分类查询接口文档

> 最后更新：2026-07-10

---

## GET /api/faq/items/ — FAQ 列表（支持分类查询）

**接口地址：** `/api/faq/items/`

**请求方式：** `GET`

**权限：** 需登录（请求头携带 `Authorization: Token xxx`）

---

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `category` | int | 否 | 分类 ID 筛选（不传则返回全部） |
| `q` | str | 否 | 关键词搜索（匹配问题、答案、标签、分类名） |
| `status` | str | 否 | 状态筛选：`draft` / `published` / `rejected` |
| `college_id` | int | 否 | 学院 ID 筛选 |
| `page` | int | 否 | 页码，默认 1 |
| `page_size` | int | 否 | 每页条数，默认 20，最大 100 |

---

### 分类 ID 获取

调 `GET /api/faq/categories/` 获取全部分类列表：

```json
[
  { "id": 1, "name": "宿舍管理", "icon": "🏠", "sort_order": 1 },
  { "id": 2, "name": "教务学籍", "icon": "📚", "sort_order": 2 },
  { "id": 3, "name": "校园卡",   "icon": "💳", "sort_order": 3 }
]
```

> 分类名仅为示例，以实际接口返回为准。

---

### 请求示例

```http
# 查询全部 FAQ
GET /api/faq/items/

# 按分类筛选
GET /api/faq/items/?category=1

# 分类 + 状态 + 分页组合
GET /api/faq/items/?category=1&status=published&page=1&page_size=10

# 关键词搜索
GET /api/faq/items/?q=宿舍

# 分类 + 搜索组合
GET /api/faq/items/?category=1&q=关门
```

### 响应格式

```json
{
  "count": 42,
  "next": "http://118.178.234.99/api/faq/items/?category=1&page=2",
  "previous": null,
  "results": [

      "answer": "宿舍楼统一23:00关门，周末延长至23:30。",

      "category_name": "宿舍管理",

      "college_name": null,
      "tags": ["宿舍", "门禁", "关门时间"],
      "frequency": 12.5,
      "status": "published",
      "created_at": "2026-07-03T10:30:00+08:00"
    }
  ]

```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `count` | int | 总条数 |
| `next` | string/null | 下一页 URL |
| `previous` | string/null | 上一页 URL |
| `results[].id` | int | FAQ ID |
| `results[].question` | string | 问题 |
| `results[].answer` | string | 答案 |
| `results[].category` | int/null | 所属分类 ID |
| `results[].category_name` | string/null | 所属分类名称 |
| `results[].college` | int/null | 所属学院 ID（null = 全局） |
| `results[].college_name` | string/null | 所属学院名称 |
| `results[].tags` | string[] | 关键词标签 |
| `results[].frequency` | float | 热度占比（%） |
| `results[].status` | string | 状态：`draft` / `published` / `rejected` |
| `results[].created_at` | datetime | 创建时间 |

## GET /api/faq/categories/ — FAQ 分类列表

**接口地址：** `/api/faq/categories/`

**请求方式：** `GET`

**权限：** 需登录

## 前端接入示例

### Vue 示例

```vue
<template>
  <div>
    <!-- 分类标签 -->
    <div class="category-tabs">
      <span
        v-for="cat in categories"
        :key="cat.id"
        :class="{ active: activeCategory === cat.id }"
        @click="selectCategory(cat.id)"
      >
        {{ cat.icon }} {{ cat.name }}
      </span>
    </div>

    <!-- FAQ 列表 -->
    <ul>
      <li v-for="item in faqList" :key="item.id">
        <h4>{{ item.question }}</h4>
        <p>{{ item.answer }}</p>
        <span>{{ item.category_name }}</span>
      </li>
    </ul>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'

const categories = ref([])
const activeCategory = ref(null)
const faqList = ref([])

// 页面加载时获取分类列表
onMounted(async () => {
  const res = await fetch('/api/faq/categories/', {
    headers: { 'Authorization': `Token ${token}` }
  })
  categories.value = await res.json()
  fetchFAQList()
})

// 选择分类
const selectCategory = (id) => {
  activeCategory.value = id
  fetchFAQList()
}

// 请求 FAQ 列表
const fetchFAQList = async () => {
  const params = new URLSearchParams({
    status: 'published',
    page: 1,
    page_size: 10,
  })
  if (activeCategory.value) {
    params.set('category', activeCategory.value)
  }

  const res = await fetch(`/api/faq/items/?${params}`, {
    headers: { 'Authorization': `Token ${token}` }
  })
  const data = await res.json()
  faqList.value = data.results
}
</script>
```

### React 示例

```jsx
import { useState, useEffect } from 'react'

function FAQPage() {
  const [categories, setCategories] = useState([])
  const [activeCategory, setActiveCategory] = useState(null)
  const [faqList, setFaqList] = useState([])

  // 页面加载时获取分类列表
  useEffect(() => {
    fetch('/api/faq/categories/', {
      headers: { Authorization: `Token ${token}` }
    })
      .then(r => r.json())
      .then(setCategories)
  }, [])

  // activeCategory 变化时重新请求
  useEffect(() => {
    const params = new URLSearchParams({ status: 'published', page: 1, page_size: 10 })
    if (activeCategory) params.set('category', activeCategory)

    fetch(`/api/faq/items/?${params}`, {
      headers: { Authorization: `Token ${token}` }
    })
      .then(r => r.json())
      .then(data => setFaqList(data.results))
  }, [activeCategory])

  return (
    <div>
      {/* 分类标签 */}
      <div className="category-tabs">
        {categories.map(cat => (
          <span
            key={cat.id}
            className={activeCategory === cat.id ? 'active' : ''}
            onClick={() => setActiveCategory(cat.id)}
          >
            {cat.icon} {cat.name}
          </span>
        ))}
      </div>

      {/* FAQ 列表 */}
      <ul>
        {faqList.map(item => (
          <li key={item.id}>
            <h4>{item.question}</h4>
            <p>{item.answer}</p>
            <span>{item.category_name}</span>
          </li>
        ))}
      </ul>
    </div>
  )
}
```

## 接入步骤总结

1. **页面初始化** → 调 `GET /api/faq/categories/` 获取分类列表，渲染分类标签
2. **用户点击分类** → 将该分类 `id` 作为 `category` 参数拼到 `/api/faq/items/` 请求中
3. **不传 `category`**（或传 `category=` 空值）→ 返回全部 FAQ
4. **可选组合** `status`、`q`、`page`、`page_size` 等参数实现搜索和分页
