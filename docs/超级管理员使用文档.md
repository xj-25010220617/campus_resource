# 校园虚拟资源管理平台超级管理员使用文档

## 一、适用对象

本手册适用于超级管理员。超级管理员负责平台整体管理，可以查看和维护全校范围内的账号、文档、FAQ、部门和日志。

超级管理员登录后，左侧菜单通常包括：

- 知识库管理
- 智能问答（进入问答页面后显示为“教研问答”）
- FAQ 管理
- 账号管理
- 部门管理
- 日志管理

## 二、登录系统

1. 打开系统首页。
2. 在登录区域输入账号和密码。
3. 点击“登录”。
4. 登录成功后，系统通常进入“知识库管理”。
5. 检查左侧菜单和右侧账号信息，确认当前登录的是超级管理员账号。

如果提示登录失败，请检查账号和密码，或联系系统维护人员。

## 三、知识库管理

### 3.1 进入知识库管理

点击左侧“知识库管理”，进入“文档列表”页面。

页面主要区域从上到下包括：

1. 上传区域；
2. “全部资料”列表；
3. 文件预览说明；
4. 搜索和筛选区域；
5. 文档表格；
6. 分页区域。

### 3.2 上传文件

1. 在页面顶部选择“上传文件”。
2. 点击上传区域，或将文件拖入上传区域。
3. 选择一个或多个文件。
4. 在待上传文件列表中点击需要设置的文件。
5. 在右侧填写或检查文件信息：
   - 文件名；
   - AI 推荐文件名；
   - 关键词；
   - 公开/私密；
   - 文件描述。
6. 如果需要使用系统推荐的文件名，点击“使用”；不采用时点击“不使用”。
7. 点击“添加”补充关键词，也可以删除不需要的关键词。
8. 检查可见范围和文件内容。
9. 点击“确认上传”。

上传完成后，文档可能需要一段时间处理。显示“处理中”时，请等待处理完成后再使用问答功能检索该文件。

上传前请注意：

- 不要上传空文件或损坏文件；
- 不要重复上传相同文件；
- 关键词应与文档内容直接相关；
- 公开资料应确认可以提供给相应用户查看或检索。

### 3.3 创建文件

“创建文件”适合直接录入文字资料。

1. 在上传区域切换到“创建文件”。
2. 输入文件正文内容。
3. 点击“确认信息”。
4. 检查系统生成或补充的文件名、关键词、描述和可见范围。
5. 根据需要修改这些信息。
6. 如果需要修改正文，点击“返回修改内容”。
7. 检查无误后点击“确认创建”。

### 3.4 搜索和筛选资料

在“全部资料”区域可以使用以下条件：

- 搜索关键词；
- 文件格式；
- 上传单位；
- 上传者。

搜索结果下方可以切换页码，每页显示数量可以选择 10、20 或 30 条。

如果页面显示“暂无文件，请上传”，先清除搜索和筛选条件，再确认资料是否确实不存在。

### 3.5 预览文件

点击文件图标或文件名，可以打开预览窗口。

系统支持在线预览的常见格式包括：

- Markdown 和文本；
- 图片；
- 音频和视频；
- PDF；
- Word（`.docx`）；
- Excel（`.xls`、`.xlsx`）；
- PPT（`.pptx`）。

通常需要下载后查看的格式包括：

- 旧版 Word（`.doc`）；
- 旧版 PPT（`.ppt`）；
- 压缩包；
- 设计源文件；
- 3D 模型；
- 电子书等。

大文件在线预览失败时，请点击“下载”后使用本地软件查看。

### 3.6 下载、编辑和删除资料

在文档表格最右侧的“操作”列中，按钮顺序为：

1. “下载”：下载原文件；
2. “编辑”：修改文件名、描述和关键词；
3. “删除”：删除文件。

编辑步骤：

1. 点击目标文件右侧的“编辑”。
2. 修改文件名、描述或关键词。
3. 点击弹窗右下角“保存”。
4. 不需要修改时点击“取消”。

删除步骤：

1. 点击目标文件右侧的“删除”。
2. 在确认窗口中核对文件名称。
3. 点击“确定”删除，或点击“取消”返回。

批量删除步骤：

1. 勾选需要删除的文件。
2. 页面出现“批量删除（数量）”按钮。
3. 核对选中文件数量。
4. 点击“批量删除（数量）”。
5. 在提示窗口中点击“确定”。

删除前请确认资料不再需要。删除后，用户可能无法继续查看或通过问答检索该资料。

### 3.7 文档详情

进入文档详情后，页面顶部通常有以下按钮：

- “AI提取日期”；
- “重命名”；
- “下载”；
- “删除”。

Markdown 或文本文件在预览区还可以使用：

- “编辑”；
- “保存”；
- “取消”。

点击“重命名”后输入新文件名，再点击“确定”。删除文件时，确认窗口会要求再次确认。

## 四、FAQ 管理

### 4.1 查看和筛选 FAQ

点击左侧“FAQ 管理”。页面上方提供：

- “搜索问题”输入框；
- “全部分类”下拉框；
- “重置”按钮。

页面中部提供状态切换：

- 全部；
- 草稿；
- 已发布；
- 已驳回。

点击问题卡片可以展开查看答案、标签和创建时间，再次点击可以收起。

### 4.2 编辑 FAQ 草稿

1. 在列表中找到状态为“草稿”的 FAQ。
2. 点击右侧“编辑”。
3. 在弹窗中修改问题、答案、分类和标签。
4. 添加标签时，可以点击已有候选标签，或在“新标签”输入框填写后点击“添加”。
5. 删除标签时，点击标签旁的关闭按钮。
6. 点击“保存”。

已发布和已驳回的 FAQ 通常不能直接编辑。

### 4.3 发布 FAQ

1. 找到状态为“草稿”的 FAQ。
2. 点击右侧“发布”。
3. 在发布确认窗口中核对问题内容。
4. 点击“确定”完成发布。

发布前必须确认答案准确、完整，并且适合对外展示。只有发布后的 FAQ 才会提供给普通用户查看。

### 4.4 驳回 FAQ

1. 找到需要退回修改的草稿。
2. 点击右侧“驳回”。
3. 在确认窗口中点击“确定”。

答案不准确、内容不完整或适用范围不明确时，建议先驳回，修改后再审核。

### 4.5 删除 FAQ

1. 点击 FAQ 右侧“删除”。
2. 核对问题内容。
3. 在确认窗口中点击“确定”。

删除提示会说明此操作不可撤销，请谨慎操作。

### 4.6 生成 FAQ

如果页面提供 FAQ 自动生成入口：

1. 打开生成功能。
2. 确认没有正在运行的生成任务。
3. 点击开始生成。
4. 等待任务完成。
5. 返回“草稿”列表检查生成内容。
6. 审核无误后，再逐条发布。

自动生成的内容只是草稿，不能直接当作正式通知或官方答案。

## 五、账号管理

### 5.1 用户账号

点击“账号管理”中的“用户账号”。

页面上方右侧有“+ 新增”按钮。搜索区域提供：

- 账号角色筛选；
- 搜索账号；
- 所属单位筛选；
- “重置”按钮。

账号表格包括：

- 序号；
- 账号；
- 角色；
- 所属单位；
- 操作。

操作列通常包括“编辑”和“删除”。

### 5.2 新增账号

1. 点击右上角“+ 新增”。
2. 填写账号。
3. 设置初始密码。
4. 选择角色。
5. 选择所属单位。
6. 点击弹窗右下角“确定”。

账号一般要求 3—20 个字符，密码至少 8 位。管理员账号必须选择正确的所属学院或部门。

### 5.3 编辑账号

1. 在账号列表中找到目标账号。
2. 点击“编辑”。
3. 修改允许修改的信息。
4. 如果不修改密码，可以留空。
5. 点击“确定”。

超级管理员账号不能通过普通编辑流程修改。不能删除自己，也不能重置自己的密码。

### 5.4 批量删除和批量修改密码

1. 勾选需要操作的账号。
2. 页面出现批量操作栏。
3. 点击“批量删除”或“批量修改密码”。
4. 核对账号数量和名单。
5. 输入新密码或确认删除。
6. 点击弹窗中的“确定”。

批量操作前务必再次核对选择结果。

## 六、所属单位管理

在“账号管理”下点击“所属单位”。页面包括两个标签：

- 学院管理；
- 部门管理。

### 6.1 学院管理

学院列表显示：

- 学院名称；
- 学院编码；
- 排序；
- 操作。

新增或编辑学院时填写：

- 学院名称；
- 学院编码；
- 排序。

排序数字越小，显示位置越靠前。

### 6.2 部门管理

部门列表显示：

- 部门名称；
- 上级单位；
- 操作。

新增或编辑部门时填写：

- 部门名称；
- 上级单位。

上级单位可以选择顶级、学院或其他部门。删除部门前，应确认其下级部门和所属用户已经完成调整。

## 七、部门管理

点击左侧“部门管理”，可以查看部门结构和部门数量。

超级管理员可以根据页面按钮进行部门新增、编辑或删除。进行结构调整前应确认：

- 部门层级是否正确；
- 部门名称是否重复；
- 是否有下级部门；
- 是否有用户归属于该部门。

## 八、日志管理

点击左侧“日志管理”。页面顶部包括：

- 概览；
- 上传日志；
- 查询日志；
- 敏感内容；
- 登录日志；
- 操作日志。

概览可以切换：

- 今天；
- 本周；
- 本月。

日志用于查看平台运行和管理情况。日志内容可能包含账号、提问内容和操作信息，只能用于管理、排查和安全审查，不要随意复制或传播。

## 九、教研问答

超级管理员进入问答页面后，页面标题显示为“教研问答”。使用方法与普通用户的智能问答基本相同：

1. 点击“新建对话”，或直接在输入框提问。
2. 在“输入你的问题…”输入问题。
3. 点击右侧发送按钮，或按 Enter。
4. 等待回答生成。
5. 查看回答、参考资料、推荐追问和相关图片。
6. 可对回答点赞或点踩。

回答生成期间，输入框会显示“AI 正在回复…”，发送按钮会变为取消按钮。回答超时后可以重新提问。

AI 回答仅供辅助参考。涉及正式通知、成绩、费用、身份和规章制度时，应核对原始资料或咨询相关部门。

## 十、个人账号和退出

点击左侧底部账号区域，可以使用“个人中心”或“退出登录”。

修改密码时应使用本人专属密码，不要与其他人员共用超级管理员账号。

## 十一、常见提示

| 提示 | 处理方法 |
|---|---|
| 文件重复 | 查找已有文件，确认是否需要再次上传 |
| 文档处理中 | 等待处理完成后再进行问答检索 |
| 文档列表加载失败 | 点击“重试”，并检查网络 |
| 暂无文件，请上传 | 清除筛选条件，确认资料是否存在 |
| FAQ 生成任务正在进行 | 等待当前任务完成，不要重复提交 |
| 无权操作 | 检查当前账号、资料归属和管理范围 |
| AI 回复超时 | 点击取消或稍后重新提问 |
| AI 回答失败 | 检查网络，换一种方式提问 |

## 十二、使用注意事项

- 上传资料前确认内容准确、来源可靠并允许使用。
- 发布 FAQ 前必须人工审核。
- 删除账号、部门、文档和 FAQ 前确认影响范围。
- 日志中可能含有个人信息，应妥善保管。
- 不要将管理员账号交给他人使用。
