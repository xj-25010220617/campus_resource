# 接口文档 - 上传日志管理接口

> 生成时间：2026-07-02
> 
> **认证说明**：所有接口均需要携带 JWT Token，格式：`Authorization: Bearer <token>`
> 
> **权限说明**：以下接口仅对 `admin` 和 `super_admin` 角色开放

---

## 一、接口概览

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/resources/upload-log/` | 上传日志列表 |
| GET | `/api/resources/upload-log/{id}/` | 上传日志详情 |
| GET | `/api/resources/upload-log/stats/` | 上传统计 |
| PATCH | `/api/resources/upload-log/{id}/complete/` | 更新上传状态（内部接口） |

---

## 二、接口详情

### 2.1 获取上传日志列表

```
GET /api/resources/upload-log/
```

**功能**：获取文件上传日志列表，支持多种过滤和排序

**权限**：admin / super_admin

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | string | 否 | 按状态过滤：`pending` / `success` / `failed` |
| file_type | string | 否 | 按文件类型过滤：`pdf` / `docx` / `xlsx` 等 |
| college | integer | 否 | 按学院ID过滤 |
| start_date | string | 否 | 开始日期（ISO 格式或 `YYYY-MM-DD`） |
| end_date | string | 否 | 结束日期（ISO 格式或 `YYYY-MM-DD`） |
| user_id | integer | 否 | 按上传用户ID过滤 |
| college_id | integer | 否 | 按学院ID过滤（与 college 等效） |
| search | string | 否 | 搜索：文件名、用户名 |
| ordering | string | 否 | 排序字段：`created_at`（默认） / `file_size`，加 `-` 前缀表示倒序 |

### 2.4 更新上传状态（内部接口）

```
PATCH /api/resources/upload-log/{id}/complete/
```

**功能**：更新上传日志的状态（成功/失败），通常由后端任务调用

**权限**：admin / super_admin

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 上传日志ID |

**请求体**（成功时）：

```json
{
  "status": "success",
  "resource_id": 10
}
```

**请求体**（失败时）：

```json
{
  "status": "failed",
  "error_message": "文件格式不支持"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | string | 是 | `success` 或 `failed` |
| resource_id | integer | 条件必填 | 成功时必填，关联的资源ID |
| error_message | string | 条件必填 | 失败时必填，错误信息描述 |

**响应示例**（HTTP 200）：

```json
{
  "id": 1,
  "user": 5,
  "user_name": "zhangsan",
  "resource": 10,
  "resource_title": "数据结构课件.pdf",
  "file_name": "data_structure.pdf",
  "file_size": 2048000,
  "file_type": "pdf",
  "college": 1,
  "college_name": "计算机学院",
  "status": "success",
  "error_message": "",
  "ip_address": "192.168.1.100",
  "user_agent": "Mozilla/5.0...",
  "created_at": "2026-07-01T10:30:00Z",
  "completed_at": "2026-07-02T14:00:00Z"

```

**错误响应**（HTTP 400）：

```json
{
  "status": ["状态必须为 'success' 或 'failed'"]
}
```

```json

}
```

```json
{
  "error_message": ["失败状态必须提供 error_message"]
}
```

## 三、状态说明

上传日志的状态流转：

```
pending（待处理）→ success（成功）
                 → failed（失败）
```

| 状态 | 说明 |
|------|------|
| `pending` | 文件正在上传或处理中 |
| `success` | 上传成功，已生成资源记录 |
| `failed` | 上传失败，需要查看 error_message |

---

## 四、典型使用场景

### 场景1：查询某时间段内的上传统计

```
GET /api/resources/upload-log/stats/?start_date=2026-07-01&end_date=2026-07-31&group_by=file_type,college
```

### 场景2：查询某个用户的全部上传记录

```
GET /api/resources/upload-log/?user_id=5&ordering=-created_at
```

### 场景3：查看上传失败记录

```
GET /api/resources/upload-log/?status=failed&ordering=-created_at
```

### 场景4：查询某学院的上传日志

```
GET /api/resources/upload-log/?college_id=1&start_date=2026-07-01
```

## 五、错误响应格式

```json
{
  "detail": "错误描述信息"
}
```

**常见 HTTP 状态码**：

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未认证（Token 无效或过期） |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
