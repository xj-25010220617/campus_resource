# 前端对接接口文档 — 标签功能（2026-10-27）

> **面向**：前端对接同学
> **范围**：标签的「上传打标、浏览展示、按标签筛选、词表管理」全链路接口。
> **后端分支**：main

---

## 0. 基础约定

| 项 | 说明 |
|---|---|
| Base URL | 所有路径前缀为 `/api/knowledge` |
| 认证 | 所有接口需携带 `Authorization: Bearer <token>`（JWT） |
| Content-Type | 请求体为 JSON 时用 `application/json` |
| 成功返回 | 直接返回数据，或 `{"detail": "操作成功"}` |
| 失败返回 | `{"detail": "错误描述", "code": "错误码"}`（HTTP 状态码见各接口） |

**角色**：`super_admin`（超管）、`admin`（管理员，含 `college_admin`/`dept_admin`，下同）、`user`（普通用户）。

---

## 1. 接口清单

| # | 方法 | 路径 | 说明 |
|---|---|---|---|
| 1 | GET | `/api/knowledge/tags/` | 查询标签词表（含文档数 `doc_count`） |
| 2 | GET | `/api/knowledge/docs/` | 文档列表（每项含 `tags`；支持 `tag_id`/`tag` 筛选） |

| 8 | POST | `/api/knowledge/tags/merge/` | 合并重复标签（词表管理） |
| 9 | DELETE | `/api/knowledge/tags/{tag_id}/delete/` | 软删标签词条（词表管理） |
| — | — | 5 个上传接口 | 上传时可选入参 `tags`（见 §3） |

## 2. 接口明细

### 2.1 查询标签词表

`GET /api/knowledge/tags/`

返回全平台共享的标签词表（软删除的不返回），按创建顺序排列。

**权限**：所有登录用户。

**响应**：

```json
[
  { "id": 1, "name": "高等数学", "created_at": "2026-10-22T10:00:00Z", "doc_count": 12 },
  { "id": 2, "name": "数据结构", "created_at": "2026-10-22T10:01:00Z", "doc_count": 7 }
]
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | int | 标签 ID |
| `name` | string | 标签名（全局唯一） |
| `created_at` | string | 创建时间 |
| `doc_count` | int | **当前登录用户可浏览范围内**打了该标签的文档数（随权限变化，前端用它渲染侧边栏/标签云计数） |

> 前端「标签云 / 侧边栏」直接用本接口：显示 `name` + `doc_count`，点击跳转 `GET /docs/?tag_id={id}`。

### 2.2 文档列表（含标签徽章 + 按标签筛选）

`GET /api/knowledge/docs/`

**新增/增强点**：
- 每项新增 `tags` 字段（标签徽章数据）。
- 新增筛选参数 `tag_id`、`tag`。

**筛选参数**（可与 `college_id`、`file_type`、`search`、`days_back` 等组合）：

| 参数 | 类型 | 说明 |
|---|---|---|
| `tag_id` | int | 按标签 ID 精确筛选，如 `?tag_id=1` |
| `tag` | string | 按标签名称精确筛选，如 `?tag=高等数学` |

**响应（节选，每项）**：

```json
{
  "id": 128,
  "title": "微积分讲义",
  "file_type": "pdf",
  "file_size": 1024000,
  "status": "indexed",
  "college_name": "计算机学院",
  "discipline_name": "软件工程",
  "uploader_name": "张三",
  "chunk_count": 24,
  "created_at": "2026-10-22T10:00:00Z",
  "created_at_display": "2026-10-22 10:00:00",
  "tags": [
    { "id": 1, "name": "高等数学" },
    { "id": 3, "name": "期中复习" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `tags` | 标签徽章数据，元素 `{id, name}`（`id` 为标签 ID，可跳筛选） |

### 2.3 文档详情（含标签）

`GET /api/knowledge/docs/{id}/`

详情响应的 `tags` 字段结构与列表不同（更完整，含关联 ID 与创建时间）：

```json
{
  "id": 128,
  "title": "微积分讲义",
  "tags": [
    { "id": 11, "tag_id": 1, "tag_name": "高等数学", "created_at": "2026-10-22T10:00:00Z" }
  ],
  "relations": [ "……（文件网关联，见关联文档）" ]
}
```

> 详情页标签点击跳转：用 `tag_id` 跳 `GET /docs/?tag_id={tag_id}`。

### 2.4 为文档批量打标签

`POST /api/knowledge/docs/{doc_id}/tags/create/`

**权限**：`super_admin` 可给任意文档打标；其他管理员角色仅能给自己上传的文档打标；普通用户不可（403）。

**请求体**：

```json
{ "names": ["高等数学", "期中复习", "新标签"] }
```

| 字段 | 说明 |
|---|---|
| `names` | 标签名数组，必填，1~20 个；单个 ≤64 字符；不存在的标签名**自动创建**；重复打标幂等 |

**响应**：

```json
{
  "created": 2,
  "tags": [
    { "id": 11, "tag_id": 1, "tag_name": "高等数学", "created_at": "..." },
    { "id": 12, "tag_id": 2, "tag_name": "期中复习", "created_at": "..." }
  ]
}
```

- `created`：本次实际新增的关联数（已存在的不重复计数）。
- `tags`：该文档**当前全部**标签，可直接回显。

### 2.5 查询某文档的标签

`GET /api/knowledge/docs/{doc_id}/tags/`

**权限**：所有登录用户（文档需在当前用户可浏览范围内，否则 404）。

**响应**：

```json
[
  { "id": 11, "tag_id": 1, "tag_name": "高等数学", "created_at": "..." }
]
```

### 2.6 移除文档上的一个标签

`DELETE /api/knowledge/docs/{doc_id}/tags/{tag_id}/delete/`

**权限**：同 2.4（仅删关联，不删词条）。

**响应**：`{"detail": "删除成功"}`

### 2.7 重命名标签（词表管理）

`POST /api/knowledge/tags/{tag_id}/rename/`

**权限**：仅 `super_admin`（词表全平台共享，重命名影响所有人）。

**请求体**：

```json
{ "name": "高数" }
```

**响应**：`{ "id": 1, "name": "高数", "created_at": "..." }`

**错误**：
- 名称为空 → `400` `{"name": "标签名不能为空"}`
- 名称 >64 字符 → `400`
- 新名称与其它标签重名 → `400` `{"name": "标签「高数」已存在，可直接使用或走合并"}`

### 2.8 合并重复标签（词表管理）

`POST /api/knowledge/tags/merge/`

**权限**：仅 `super_admin`。

**请求体**：

```json
{ "source_tag_id": 2, "target_tag_id": 1 }
```

| 字段 | 说明 |
|---|---|
| `source_tag_id` | 被合并的源标签 ID（合并后软删） |
| `target_tag_id` | 保留的目标标签 ID |

**行为**：源标签的所有文档关联改指向目标标签（文档已有目标标签时跳过，不产生重复关联），随后软删源词条。

**响应**：

```json
{
  "detail": "合并成功",
  "moved": 5,
  "tag": { "id": 1, "name": "高等数学", "created_at": "..." }
}
```

- `moved`：本次实际迁移的文档关联数。

**错误**：
- 参数缺失 → `400`
- 源与目标相同 → `400` `{"detail": "源标签与目标标签不能相同"}`

### 2.9 软删标签词条（词表管理）

`DELETE /api/knowledge/tags/{tag_id}/delete/`

**权限**：仅 `super_admin`。

**行为**：软删词条（不再出现在 `GET /tags/`），并移除该标签在全部文档上的关联；不影响文档本身与其他标签。

**响应**：`{"detail": "删除成功"}`

## 3. 上传时打标

以下 5 个上传接口在原参数基础上新增可选入参 `tags`：

| 接口 | 路径 |
|---|---|
| 单文件上传 | `POST /api/knowledge/upload/file/` |
| 批量上传 | `POST /api/knowledge/upload/batch/` |
| 文本录入 | `POST /api/knowledge/upload/text/` |
| OSS 直传回调 | `POST /api/knowledge/upload/callback/` |
| 分片合并上传 | `POST /api/knowledge/upload/chunk/merge/` |

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `tags` | `string[]` | 否 | 标签名列表（与 `keywords` 分离）。不传则不打标 |

**JSON 示例**（文本录入 / OSS 回调）：

```json
{
  "content": "……",
  "visibility": "public",
  "keywords": ["微积分", "高数"],
  "tags": ["高等数学", "期中复习"]
}
```

**multipart 说明**：`tags` 兼容三种传法——重复字段 `tags=a&tags=b`、JSON 字符串 `tags='["a","b"]'`、数组命名字段 `tags[]=a&tags[]=b`。

## 4. 权限矩阵

| 能力 | super_admin | admin（含 college/dept admin） | user |
|---|---|---|---|
| 查词表 / 查文档标签 | ✅ | ✅ | ✅（仅可浏览范围） |
| 打标签 / 删文档标签 | ✅ 任意文档 | ✅ 仅本人上传文档 | ❌ |
| 词表管理（重命名 / 合并 / 软删） | ✅ | ❌ | ❌ |

---

## 5. 前端对接建议（交互闭环）

1. **上传**：上传前 `GET /tags/` 拉词表做联想/候选；上传时把用户勾选的标签放进 `tags`。
2. **列表页**：每个文档卡片右上角渲染 `tags` 徽章（`tags[].name`）。
3. **侧边栏/标签云**：用 `GET /tags/` 的 `id` / `name` / `doc_count` 渲染。
4. **点标签筛选**：点徽章或侧边栏标签 → 跳 `GET /docs/?tag_id={id}`（或 `?tag={name}`）。
5. **详情页**：`tags`（`{tag_id, tag_name}`）做成可点击，同样跳筛选列表。
6. **管理员词表维护**：后台提供「重命名 / 合并 / 删除」入口，对应接口 2.7 / 2.8 / 2.9。

## 6. 常见错误码

| 场景 | HTTP | 返回 |
|---|---|---|
| 给他人文档打标 / 删标签 | 403 | `{"detail": "只能给自己上传的文档打标签"}` |
| 非管理员调用打标 | 403 | 权限类拦截 |
| 词表管理非超管 | 403 | `{"detail": "仅超级管理员可管理标签词表"}` |
| 重命名重名 | 400 | `{"detail": "标签「xx」已存在，可直接使用或走合并", "code": "..."}`（`name` 字段错误） |
| 标签名列表为空 | 400 | `names` 校验失败 |
