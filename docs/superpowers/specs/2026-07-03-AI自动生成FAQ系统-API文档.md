# AI 自动生成 FAQ 系统 — API 接口文档

## 热点问题

### GET /api/chat/hot-questions/

获取近期热点问题列表（"大家都在问"），展示在智能问答主界面。

**权限：** 登录用户

**参数：**
| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| days | int | 否 | 7 | 统计最近几天 |
| top_k | int | 否 | 10 | 返回条数 |

**响应：**
```json
[
  {
    "question": "如何重置密码？",
    "count": 45
  }
]
```

## FAQ 公共接口

### GET /api/faq/categories/

获取 FAQ 分类列表。

**权限：** 登录用户

**响应：**
```json
[
  {
    "id": 1,
    "name": "选课相关",
    "icon": "book",
    "sort_order": 0
  }
]
```

---

### GET /api/faq/items/

获取已发布的 FAQ 列表。

**权限：** 登录用户

**过滤规则：**
- 仅返回 `status='published'` 的条目
- 自动根据用户所在学院展示：**全局 FAQ（college=null）+ 本学院 FAQ（college=用户所在学院）**
- 按 `frequency`（占比）降序排列

**响应：**
```json
[
  {
    "id": 1,
    "question": "如何重置密码？",
    "answer": "您可以通过以下步骤重置密码...",
    "category": 1,
    "category_name": "账号问题",
    "college": null,
    "college_name": null,
    "tags": ["密码", "登录", "账号"],
    "frequency": 3.5,
    "created_at": "2026-07-01T10:00:00Z"
  }
]
```

---

## FAQ 管理接口

### GET /api/faq/drafts/

待审核草稿列表。

**权限：** `super_admin` / `college_admin` / `dept_admin`

**角色过滤：**
- `super_admin`：全部草稿
- `college_admin` / `dept_admin`：全局草稿 + 本学院草稿

**响应：** 同 `GET /api/faq/items/` 格式，但包含所有 `status='draft'` 的条目。

---

### GET /api/faq/drafts/{id}/

草稿详情。

**权限：** 同上

**响应：**
```json
{
  "id": 1,
  "question": "如何重置密码？",
  "answer": "...",
  "category": 1,
  "college": null,
  "tags": ["密码", "登录"],
  "status": "draft",
  "frequency": 3.5,
  "variant_count": 12,
  "source_period_start": "2026-06-24T03:00:00Z",
  "source_period_end": "2026-07-01T03:00:00Z",
  "related_doc_ids": [],
  "reviewed_by": null,
  "reviewed_at": null,
  "created_at": "2026-07-01T10:00:00Z",
  "updated_at": "2026-07-01T10:00:00Z"
}
```

---

### PATCH /api/faq/drafts/{id}/

编辑草稿。

**权限：** 同上

**请求：**
```json
{
  "question": "修改后的问题",
  "answer": "修改后的答案",
  "category": 2,
  "tags": ["新标签1", "新标签2"]
}
```

---

### POST /api/faq/drafts/{id}/action/

发布或驳回草稿。

**权限：** 同上

**请求：**
```json
{ "action": "publish" }
// 或
{ "action": "reject" }
```

**响应：**
```json
{
  "status": "ok",
  "faq_id": 1,
  "new_status": "published"
}
```

---

### GET /api/faq/manage/items/

管理端全部 FAQ 列表（含草稿 / 已发布 / 已驳回）。

**权限：** 同上

---

### DELETE /api/faq/manage/items/{id}/

删除 FAQ 条目。

**权限：** 同上

**响应：** `204 No Content`

---

## 管理后台（Django Admin）

路径：`/admin/faq/`

| 模型 | 功能 |
|------|------|
| FAQCategory | 管理 FAQ 分类 |
| FAQItem | 管理 FAQ 条目（支持批量发布/驳回操作） |
| FAQGenerationLog | 查看 AI 生成历史日志（只读） |
