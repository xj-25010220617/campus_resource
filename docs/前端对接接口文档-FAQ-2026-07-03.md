## 一、热点问题（智能问答主界面）

### 1.1 获取热点问题列表

```
GET /api/chat/hot-questions/
```

**功能**：展示在智能问答主界面底部/侧边栏的"大家都在问"列表，实时统计近期用户高频提问。

**权限**：登录用户

**请求参数**（Query）：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `days` | int | 否 | `7` | 统计最近 N 天的数据 |
| `top_k` | int | 否 | `10` | 返回前 K 条高频问题 |

**Apifox 配置**：

```
请求方式: GET
路径: {{base_url}}/api/chat/hot-questions/?days=7&top_k=10
Headers:
  Authorization: Bearer {{token}}
```

**响应示例**：

```json
[
  {
    "question": "如何重置密码？",
    "count": 45
  },
  {
    "question": "图书馆几点关门？",
    "count": 32
  },
  {
    "question": "助学金申请条件是什么？",
    "count": 28
  }
]
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `question` | string | 用户提问原文（去重后） |
| `count` | int | 该问题被问的次数 |

## 二、FAQ 公共接口（常见问题页面）

### 2.1 获取 FAQ 分类列表

```
GET /api/faq/categories/
```

**功能**：获取所有 FAQ 分类，用于前端展示分类 Tab 或下拉筛选。

**权限**：登录用户

**Apifox 配置**：

```
请求方式: GET
路径: {{base_url}}/api/faq/categories/
Headers:
  Authorization: Bearer {{token}}
```

**响应示例**：

```json
[
  {
    "id": 1,
    "name": "账号相关",
    "icon": "",
    "sort_order": 0
  },
  {
    "id": 2,
    "name": "选课相关",
    "icon": "",
    "sort_order": 1
  }
]
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 分类 ID |
| `name` | string | 分类名称 |
| `icon` | string | 图标标识（暂为空） |
| `sort_order` | int | 排序号，升序排列 |

---

### 2.2 获取已发布的 FAQ 列表

```
GET /api/faq/items/
```

**功能**：获取已发布的 FAQ 条目列表，用于常见问题页面展示。

**权限**：登录用户

**过滤规则**：
- 仅返回 `status='published'` 的条目
- **自动根据用户所属学院过滤**：用户会看到「全局 FAQ」+「自己学院的 FAQ」
- 按 `frequency`（占比）降序排列

**Apifox 配置**：

```
请求方式: GET
路径: {{base_url}}/api/faq/items/
Headers:
  Authorization: Bearer {{token}}
```

**响应示例**：

```json
[
  {
    "id": 1,
    "question": "如何重置教务系统密码？",
    "answer": "您可以通过以下步骤重置密码：\n1. 访问教务系统登录页\n2. 点击「忘记密码」\n3. 输入学号和身份证号\n4. 按照短信提示重置",
    "category": 1,
    "category_name": "账号相关",
    "college": null,
    "college_name": null,
    "tags": ["密码", "登录", "教务系统"],
    "frequency": 3.5,
    "created_at": "2026-07-01T10:00:00Z"
  },
  {
    "id": 2,
    "question": "计算机学院选修课有哪些？",
    "answer": "计算机学院本学期开设的选修课包括：...",
    "category": 2,
    "category_name": "选课相关",
    "college": 3,
    "college_name": "计算机学院",
    "tags": ["选修课", "计算机学院"],
    "frequency": 2.1,
    "created_at": "2026-07-01T11:00:00Z"
  }
]
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | FAQ 条目 ID |
| `question` | string | 标准化问题 |
| `answer` | string | 标准答案（Markdown 格式） |
| `category` | int/null | 所属分类 ID |
| `category_name` | string/null | 分类名称 |
| `college` | int/null | **NULL=全局可见，有值=仅该学院可见** |
| `college_name` | string/null | 学院名称 |
| `tags` | string[] | 关键词标签 |
| `frequency` | float | 该问题在日志中占比(%) |
| `created_at` | datetime | 创建时间 |

### 2.3 获取 FAQ 详情

```
GET /api/faq/items/{id}/
```

**功能**：获取单条 FAQ 完整信息，可用于详情页展示。

**权限**：登录用户

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | int | 是 | FAQ 条目 ID |

**Apifox 配置**：

```
请求方式: GET
路径: {{base_url}}/api/faq/items/1/
Headers:
  Authorization: Bearer {{token}}
```

**响应示例**：

```json
{
  "id": 1,
  "question": "如何重置教务系统密码？",
  "answer": "您可以通过以下步骤重置密码：\n1. 访问教务系统登录页\n2. 点击「忘记密码」\n3. 输入学号和身份证号\n4. 按照短信提示重置",
  "category": 1,
  "category_name": "账号相关",
  "college": null,
  "college_name": null,
  "tags": ["密码", "登录", "教务系统"],
  "frequency": 3.5,
  "variant_count": 12,
  "source_period_start": "2026-06-24T03:00:00Z",
  "source_period_end": "2026-07-01T03:00:00Z",
  "created_at": "2026-07-01T10:00:00Z",
  "updated_at": "2026-07-01T10:30:00Z"
}
```

**额外字段说明**（相比列表接口）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `variant_count` | int | 合并的相似问法数量（AI 聚类时合并了多少条相似问题） |
| `source_period_start` | datetime | 该 FAQ 来源的日志起始时间 |
| `source_period_end` | datetime | 该 FAQ 来源的日志结束时间 |
| `updated_at` | datetime | 最后更新时间 |

## 三、FAQ 管理接口（管理员后台）

### 3.1 获取待审核草稿列表

```
GET /api/faq/drafts/
```

**功能**：获取 AI 自动生成、待管理员审核的 FAQ 草稿。

**权限**：`super_admin` | `college_admin` | `dept_admin` | `admin`

**角色数据范围**：

| 角色 | 可见范围 |
|------|---------|
| `super_admin` | 全部草稿 |
| `college_admin` | 全局草稿 + 本学院草稿 |
| `dept_admin` / `admin` | 全局草稿 + 本学院草稿 |

**Apifox 配置**：

```
请求方式: GET
路径: {{base_url}}/api/faq/drafts/
Headers:
  Authorization: Bearer {{token}}
```

**响应格式**：同 `GET /api/faq/items/`，仅返回 `status='draft'` 的条目。

---

```
GET /api/faq/drafts/{id}/

**功能**：查看单条草稿的完整信息。

**路径参数**：

| `id` | int | 是 | 草稿 ID |

**Apifox 配置**：

```
请求方式: GET
路径: {{base_url}}/api/faq/drafts/1/

  Authorization: Bearer {{token}}

### 3.3 编辑草稿

```
PATCH /api/faq/drafts/{id}/
```

**功能**：管理员编辑草稿的问题、答案、分类等字段。

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | int | 是 | 草稿 ID |

**请求体**（JSON，所有字段可选，只传需要修改的字段）：

```json
{
  "question": "修改后的标准问题",
  "answer": "修改后的标准答案",
  "category": 2,
  "tags": ["新标签1", "新标签2"]
}
```

**Apifox 配置**：

```
请求方式: PATCH
路径: {{base_url}}/api/faq/drafts/1/
Headers:
  Authorization: Bearer {{token}}
  Content-Type: application/json
Body: raw JSON
```

**响应**：返回更新后的完整草稿对象。

---

### 3.4 发布/驳回草稿

```
POST /api/faq/drafts/{id}/action/
```

**功能**：管理员审核草稿后，发布为正式 FAQ 或驳回。

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | int | 是 | 草稿 ID |

**请求体**（JSON）：

```json
{
  "action": "publish"
}
```

| 值 | 说明 |
|----|------|
| `"publish"` | 发布草稿，状态 → `published` |
| `"reject"` | 驳回草稿，状态 → `rejected` |

**Apifox 配置**：

```
请求方式: POST
路径: {{base_url}}/api/faq/drafts/1/action/
Headers:
  Authorization: Bearer {{token}}
  Content-Type: application/json
Body: raw JSON → {"action": "publish"}
```

**响应示例**：

```json
{
  "status": "ok",
  "faq_id": 1,
  "new_status": "published"
}
```

---

### 3.5 管理端查看全部 FAQ

```
GET /api/faq/manage/items/
```

**功能**：管理员查看所有 FAQ 条目（包括草稿/已发布/已驳回），比公共接口多看到非发布状态的条目。

**权限**：同上

**Apifox 配置**：

```
请求方式: GET
路径: {{base_url}}/api/faq/manage/items/
Headers:
  Authorization: Bearer {{token}}
```

**响应**：同 `GET /api/faq/items/` 格式，但包含全部状态。

---

### 3.6 删除 FAQ

```
DELETE /api/faq/manage/items/{id}/
```

**功能**：删除指定 FAQ 条目（物理删除）。

**路径参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | int | 是 | FAQ 条目 ID |

**Apifox 配置**：

```
请求方式: DELETE
路径: {{base_url}}/api/faq/manage/items/1/
Headers:
  Authorization: Bearer {{token}}
```

**响应**：`204 No Content`（无返回体）

## 四、Apifox 快速导入指南

### 4.1 环境变量配置

在 Apifox → 环境管理 → `本地开发` 环境添加：

| 变量名 | 初始值 | 说明 |
|--------|--------|------|
| `base_url` | `http://127.0.0.1:8000` | 后端地址 |
| `token` | *(留空)* | 登录后填入 access token |

### 4.2 接口分组建议

在 Apifox 项目中创建以下文件夹：

```
📁 FAQ 系统
  ├── 📁 热点问题
  │   └── GET  获取热点问题列表
  ├── 📁 FAQ 公共接口
  │   ├── GET  获取 FAQ 分类列表
  │   ├── GET  获取 FAQ 列表
  │   └── GET  获取 FAQ 详情
  └── 📁 FAQ 管理接口
      ├── GET  获取草稿列表
      ├── GET  获取草稿详情
      ├── PATCH  编辑草稿
      ├── POST  发布/驳回草稿
      ├── GET  管理端查看全部
      └── DELETE  删除 FAQ
```

### 4.3 接口总览表

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/chat/hot-questions/` | 登录用户 | 热点问题列表 |
| GET | `/api/faq/categories/` | 登录用户 | FAQ 分类列表 |
| GET | `/api/faq/items/` | 登录用户 | 已发布 FAQ 列表 |
| GET | `/api/faq/items/{id}/` | 登录用户 | FAQ 详情 |
| GET | `/api/faq/drafts/` | 管理员 | 草稿列表 |
| GET | `/api/faq/drafts/{id}/` | 管理员 | 草稿详情 |
| PATCH | `/api/faq/drafts/{id}/` | 管理员 | 编辑草稿 |
| POST | `/api/faq/drafts/{id}/action/` | 管理员 | 发布/驳回 |
| GET | `/api/faq/manage/items/` | 管理员 | 全部 FAQ |
| DELETE | `/api/faq/manage/items/{id}/` | 管理员 | 删除 FAQ |
