## 一、Chat 问答接口

### 1.1 AI 问答（流式）

```
POST /api/chat/ask/
```

**功能**：向 AI 助手提问，返回 SSE 流式响应

**权限**：登录用户

**请求体**：

```json
{
  "question": "如何申请助学金？需要准备哪些材料？",
  "conversation_id": null
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| question | string | 是 | 用户提问（最长 2000 字符） |
| conversation_id | integer/null | 否 | 会话ID，不传则创建新会话 |

**响应类型**：SSE 流式响应 `text/event-stream`

**SSE 事件格式**：

| 事件类型 | data 内容 | 说明 |
|----------|-----------|------|
| `start` | `{"conversation_id": 1, "message_id": 10}` | 会话开始，包含会话ID和消息ID |
| `token` | `{"content": "单个字符或词组"}` | AI 回答内容，逐字推送 |
| `suggested` | `["推荐问题1", "推荐问题2", "推荐问题3"]` | AI 推荐的相关问题 |
| `references` | `{"count": 3, "summary": "参考了3份文档"}` | 引用溯源摘要 |
| `references_detail` | `[{"doc_id": 1, "doc_title": "...", ...}]` | 引用详情（仅 admin/super_admin 可见） |
| `done` | `{"message_id": 10}` | 回答完成 |
| `error` | `{"detail": "错误信息"}` | 发生错误 |

**完整响应示例**：

```
event: start
data: {"conversation_id": 1, "message_id": 10}

event: token
data: {"content": "申请"}

event: token
data: {"content": "助学金"}

event: token
data: {"content": "需要准备以下材料："}

event: suggested
data: ["助学金申请条件是什么？", "助学金每年什么时候发放？", "助学金金额是多少？"]

event: references
data: {"count": 2, "summary": "参考了2份文档"}

event: references_detail
data: [{"doc_id": 1, "doc_title": "助学金申请指南.pdf"}, {"doc_id": 2, "doc_title": "学生资助政策.pdf"}]

event: done
data: {"message_id": 10}
```

**前端消费示例**（fetch + ReadableStream）：

```javascript
async function askQuestion(question, conversationId = null) {
  const response = await fetch('/api/chat/ask/', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer ' + token,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ question, conversation_id: conversationId })
  });

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let conversationId = null;
  let messageId = null;
  let fullAnswer = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value);
    const lines = chunk.split('\n');

    for (const line of lines) {
      if (line.startsWith('event: ')) {
        currentEvent = line.slice(7);
      } else if (line.startsWith('data: ')) {
        const data = JSON.parse(line.slice(6));
        
        switch (currentEvent) {
          case 'start':
            conversationId = data.conversation_id;
            messageId = data.message_id;
            console.log('开始会话:', conversationId);
            break;
          case 'token':
            fullAnswer += data.content;
            // 更新UI显示
            document.getElementById('answer').textContent = fullAnswer;
            break;
          case 'suggested':
            console.log('推荐问题:', data);
            break;
          case 'references':
            console.log('引用摘要:', data);
            break;
          case 'done':
            console.log('回答完成，消息ID:', data.message_id);
            break;
        }
      }
    }
  }
}
```

### 1.2 消息反馈（点赞/点踩）

```
POST /api/chat/message/{id}/rate/
```

**功能**：对 AI 回答进行点赞或点踩反馈

**权限**：登录用户

**路径参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 消息ID |

**请求体**：

```json
{
  "rating": "like"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| rating | string | 是 | `like` = 点赞，`dislike` = 点踩 |

**响应示例**（HTTP 200）：

```json
{
  "status": "ok",
  "rating": "like"
}
```

**错误响应**（HTTP 403）：

```json
{
  "detail": "无权对此消息进行反馈"
}
```

## 二、Admin 管理接口

> **权限说明**：以下接口仅对 `admin` 和 `super_admin` 角色开放

---

### 2.1 重置单个用户密码

```
POST /api/admin/users/{id}/reset_password/
```

**功能**：管理员重置指定用户的登录密码

**权限**：admin / super_admin

**路径参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 用户ID |

**请求体**：

```json
{
  "new_password": "NewPassword123!",
  "password_confirm": "NewPassword123!"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| new_password | string | 是 | 新密码 |
| password_confirm | string | 是 | 确认新密码 |

**响应示例**（HTTP 200）：

```json
{
  "detail": "密码重置成功"
}
```

**错误响应**：

```json
// 无权重置（HTTP 403）
{
  "detail": "无权重置此用户的密码"
}

// 不能重置自己（HTTP 400）
{
  "detail": "不能重置自己的密码"
}
```

**权限约束**：
- `admin` 角色只能重置 `user` 角色用户的密码
- 不能重置自己的密码

---

### 2.2 批量重置用户密码

```
POST /api/admin/users/batch_reset_password/
```

**功能**：管理员批量重置多个用户的登录密码

**权限**：admin / super_admin

**请求体**：

```json
{
  "user_ids": [1, 2, 3, 4, 5],
  "new_password": "DefaultPassword123!"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_ids | array[integer] | 是 | 用户ID列表（最多 100 个） |
| new_password | string | 是 | 新密码 |

**响应示例**（HTTP 200）：

```json
{
  "detail": "批量重置完成：成功 5 个，失败 0 个",
  "success_count": 5,
  "fail_count": 0,
  "fail_reasons": null
}
```

**带失败的响应示例**：

```json
{
  "detail": "批量重置完成：成功 3 个，失败 2 个",
  "success_count": 3,
  "fail_count": 2,
  "fail_reasons": [
    {
      "id": 4,
      "username": "testuser",
      "reason": "无权重置此用户"
    },
    {
      "id": 5,
      "reason": "用户不存在"
    }
  ]
}
```

**错误响应**（HTTP 400）：

```json
// 超过数量限制
{
  "detail": "一次最多删除100个用户"
}
```

## 三、公共说明

### 3.1 错误响应格式

```json
{
  "detail": "错误描述信息"
}
```

### 3.2 常见 HTTP 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 201 | 创建成功 |
| 204 | 删除成功（无响应体） |
| 400 | 请求参数错误 |
| 401 | 未认证（Token 无效或过期） |
| 403 | 无权限访问 |
| 404 | 资源不存在 |

### 3.3 批量操作说明

批量操作（重置密码、删除用户）具有以下特性：
- 返回结果包含成功数量和失败数量
- 部分失败时仍返回 HTTP 200
- `fail_reasons` 数组详细列出每个失败项的原因
- 单次请求最多处理 100 个
