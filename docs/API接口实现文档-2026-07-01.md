## 一、Chat 模块 — 会话与消息管理（7 个接口）

### 1.1 会话管理

#### 1.1.1 会话列表

| 项目 | 说明 |
|------|------|
| **接口** | `GET /api/chat/conversations/` |
| **功能** | 返回当前用户的会话列表（不含消息详情），按更新时间倒序 |
| **权限** | `IsAuthenticated` |
| **返回** | `[{id, title, created_at, updated_at}, ...]` |

#### 1.1.2 会话详情

| 项目 | 说明 |
|------|------|
| **接口** | `GET /api/chat/conversations/{id}/` |
| **功能** | 返回指定会话的完整消息列表 |
| **权限** | `IsAuthenticated`（仅本人） |
| **返回** | `{id, title, messages: [{id, role, content, references, rating, created_at}], created_at, updated_at}` |

#### 1.1.3 新建会话

| 项目 | 说明 |
|------|------|
| **接口** | `POST /api/chat/conversations/` |
| **功能** | 创建新会话 |
| **权限** | `IsAuthenticated` |
| **参数** | `{title: string}` |
| **返回** | `{id, title, created_at, updated_at}` |

#### 1.1.4 编辑会话

| 项目 | 说明 |
|------|------|
| **接口** | `PATCH /api/chat/conversations/{id}/` |
| **功能** | 修改会话标题 |
| **权限** | `IsAuthenticated`（仅本人） |
| **参数** | `{title: string}` |
| **返回** | 更新后的会话对象 |

#### 1.1.5 删除会话

| 项目 | 说明 |
|------|------|
| **接口** | `DELETE /api/chat/conversations/{id}/` |
| **功能** | 删除指定会话（级联删除所有消息） |
| **权限** | `IsAuthenticated`（仅本人） |
| **返回** | `204 No Content` |

---

### 1.2 AI 问答

#### 1.2.1 AI 问答（SSE 流式）

| 项目 | 说明 |
|------|------|
| **接口** | `POST /api/chat/ask/` |
| **功能** | 接收用户提问 → LLM 解析 → 三层检索 → 生成回答 |
| **权限** | `IsAuthenticated` |
| **参数** | `{conversation_id?: int, question: string}` |
| **返回** | SSE 流式响应 `text/event-stream` |

---

### 1.3 消息反馈

#### 1.3.1 消息反馈

| 项目 | 说明 |
|------|------|
| **接口** | `POST /api/chat/message/{id}/rate/` |
| **功能** | 用户对 AI 回答点赞/点踩 |
| **权限** | `IsAuthenticated`（消息所属用户） |
| **参数** | `{rating: "like" \| "dislike"}` |
| **返回** | `{status: "ok", rating: string}` |

#### 1.3.2 查看引用来源

| 项目 | 说明 |
|------|------|
| **接口** | `GET /api/chat/message/{id}/references/` |
| **功能** | 查看 AI 回答引用的资源列表 |
| **权限** | `IsAuthenticated` + `admin/super_admin` |
| **返回** | `[{id, title, description, file_type, ...}, ...]` |

## 二、Admin 模块 — 用户管理（4 个接口）

### 2.1 用户管理

#### 2.1.1 用户列表

| 项目 | 说明 |
|------|------|
| **接口** | `GET /api/admin/users/` |
| **功能** | 获取用户列表（分页） |
| **权限** | `admin` 或 `super_admin` |
| **过滤参数** | `role`, `college_id`, `is_active` |
| **返回** | 分页用户列表 |

#### 2.1.2 新建用户

| 项目 | 说明 |
|------|------|
| **接口** | `POST /api/admin/users/` |
| **功能** | 创建新用户 |
| **权限** | `admin` 或 `super_admin` |
| **参数** | `{username, email, password, password_confirm, role, college, phone, ...}` |
| **返回** | 创建的用户对象 |

#### 2.1.3 编辑用户

| 项目 | 说明 |
|------|------|
| **接口** | `PUT /api/admin/users/{id}/` |
| **功能** | 编辑用户信息 |
| **权限** | `admin`（仅普通用户）/ `super_admin` |
| **参数** | `{email, first_name, last_name, role, college, phone, avatar, is_active}` |
| **返回** | 更新后的用户对象 |

#### 2.1.4 删除用户

| 项目 | 说明 |
|------|------|
| **接口** | `DELETE /api/admin/users/{id}/` |
| **功能** | 删除用户 |
| **权限** | `admin`（仅普通用户）/ `super_admin` |
| **约束** | 不能删除自己，不能删除同级超管 |
| **返回** | `204 No Content` |
