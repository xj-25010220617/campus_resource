# 接口文档 - 前端对接指南

> 生成时间：2026-07-02
> 
> **认证说明**：所有接口均需要携带 JWT Token，格式：`Authorization: Bearer <token>`

---

## 一、Chat 会话接口

### 1.1 获取会话列表

```
GET /api/chat/conversations/
```

**功能**：获取当前用户的会话列表，按更新时间倒序排列

**权限**：登录用户

**请求参数**：
无

**响应示例**：

```json
[
  {
    "id": 1,
    "title": "如何申请助学金？",
    "created_at": "2026-07-01T10:30:00Z",
    "updated_at": "2026-07-01T10:35:00Z"
  },
  {
    "id": 2,
    "title": "图书馆开放时间",
    "created_at": "2026-07-02T09:00:00Z",
    "updated_at": "2026-07-02T09:05:00Z"
  }
]
```

---

### 1.2 获取会话详情

```
GET /api/chat/conversations/{id}/
```

**功能**：获取指定会话的完整消息列表

**权限**：登录用户（只能查看自己的会话）

**路径参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 会话ID |

**响应示例**：

```json
{
  "id": 1,
  "title": "如何申请助学金？",
  "messages": [
    {
      "id": 1,
      "role": "user",
      "content": "如何申请助学金？需要准备哪些材料？",
      "references": null,
      "created_at": "2026-07-01T10:30:00Z"
    },
    {
      "id": 2,
      "role": "assistant",
      "content": "申请助学金需要准备以下材料：...",
      "references": [
        {"doc_id": 123, "doc_title": "助学金申请指南.pdf"}
      ],
      "created_at": "2026-07-01T10:30:05Z"
    }
  ],
  "created_at": "2026-07-01T10:30:00Z",
  "updated_at": "2026-07-01T10:35:00Z"
}
```

---

### 1.3 新建会话

```
POST /api/chat/conversations/
```

**功能**：创建一个新的会话

**权限**：登录用户

**请求体**（可选）：

```json
{
  "title": "会话标题"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 否 | 会话标题，不超过50字符 |

**响应示例**（HTTP 201）：

```json
{
  "id": 3,
  "title": "会话标题",
  "created_at": "2026-07-02T14:00:00Z",
  "updated_at": "2026-07-02T14:00:00Z"
}
```

---

### 1.4 编辑会话

```
PATCH /api/chat/conversations/{id}/
```

**功能**：修改会话标题

**权限**：登录用户（只能修改自己的会话）

**路径参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 会话ID |

**请求体**：

```json
{
  "title": "新的会话标题"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 新的会话标题，不超过50字符 |

**响应示例**（HTTP 200）：

```json
{
  "id": 1,
  "title": "新的会话标题",
  "created_at": "2026-07-01T10:30:00Z",
  "updated_at": "2026-07-02T14:00:00Z"
}
```

---

### 1.5 删除会话

```
DELETE /api/chat/conversations/{id}/
```

**功能**：删除指定会话及其所有消息

**权限**：登录用户（只能删除自己的会话）

**路径参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 会话ID |

**响应示例**（HTTP 204）：无响应体

---

## 二、Admin 用户管理接口

> **权限说明**：以下接口仅对 `admin` 和 `super_admin` 角色开放

---

### 2.1 获取用户列表

```
GET /api/admin/users/
```

**功能**：获取用户列表，支持多种过滤条件

**权限**：admin / super_admin

**查询参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| role | string | 否 | 按角色过滤：`user` / `admin` / `super_admin` |
| college_id | integer | 否 | 按学院ID过滤 |
| is_active | boolean | 否 | 按激活状态过滤：`true` / `false` |

**响应示例**：

```json
[
  {
    "id": 1,
    "username": "zhangsan",
    "email": "zhangsan@example.com",
    "first_name": "三",
    "last_name": "张",
    "role": "user",
    "role_display": "普通用户",
    "college": 1,
    "college_name": "计算机学院",
    "phone": "13800138000",
    "avatar": "/media/avatars/zhangsan.jpg",
    "is_active": true,
    "date_joined": "2026-01-01T00:00:00Z",
    "last_login": "2026-07-02T10:00:00Z",
    "resource_count": 5
  },
  {
    "id": 2,
    "username": "lisi",
    "email": "lisi@example.com",
    "first_name": "四",
    "last_name": "李",
    "role": "admin",
    "role_display": "管理员",
    "college": 1,
    "college_name": "计算机学院",
    "phone": "13900139000",
    "avatar": null,
    "is_active": true,
    "date_joined": "2026-01-15T00:00:00Z",
    "last_login": "2026-07-02T09:00:00Z",
    "resource_count": 10
  }
]
```

**返回字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer | 用户ID |
| username | string | 用户名 |
| email | string | 邮箱 |
| first_name | string | 名 |
| last_name | string | 姓 |
| role | string | 角色：`user` / `admin` / `super_admin` |
| role_display | string | 角色显示名 |
| college | integer | 学院ID |
| college_name | string | 学院名称 |
| phone | string | 手机号 |
| avatar | string/null | 头像URL |
| is_active | boolean | 是否激活 |
| date_joined | datetime | 注册时间 |
| last_login | datetime | 最后登录时间 |
| resource_count | integer | 上传资源数量 |

---

### 2.2 新建用户

```
POST /api/admin/users/
```

**功能**：创建一个新用户账号

**权限**：admin / super_admin

**请求体**：

```json
{
  "username": "newhuser",
  "email": "newuser@example.com",
  "password": "SecurePassword123!",
  "password_confirm": "SecurePassword123!",
  "first_name": "新",
  "last_name": "用户",
  "role": "user",
  "college": 1,
  "phone": "13700137000",
  "avatar": null
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名（唯一） |
| email | string | 是 | 邮箱地址 |
| password | string | 是 | 密码 |
| password_confirm | string | 是 | 确认密码 |
| first_name | string | 否 | 名 |
| last_name | string | 否 | 姓 |
| role | string | 否 | 角色，默认 `user` |
| college | integer | 否 | 学院ID |
| phone | string | 否 | 手机号 |
| avatar | string | 否 | 头像URL |

**响应示例**（HTTP 201）：

```json
{
  "id": 10,
  "username": "newuser",
  "email": "newuser@example.com",
  "first_name": "新",
  "last_name": "用户",
  "role": "user",
  "role_display": "普通用户",
  "college": 1,
  "college_name": "计算机学院",
  "phone": "13700137000",
  "avatar": null,
  "is_active": true,
  "date_joined": "2026-07-02T14:30:00Z",
  "last_login": null,
  "resource_count": 0
}
```

---

### 2.3 编辑用户

```
PUT /api/admin/users/{id}/
```

**功能**：完整更新用户信息

**权限**：admin / super_admin

**路径参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 用户ID |

**请求体**：

```json
{
  "email": "updated@example.com",
  "first_name": "更新",
  "last_name": "用户",
  "role": "admin",
  "college": 2,
  "phone": "13600136000",
  "is_active": true
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| email | string | 是 | 邮箱地址 |
| first_name | string | 否 | 名 |
| last_name | string | 否 | 姓 |
| role | string | 否 | 角色 |
| college | integer | 否 | 学院ID |
| phone | string | 否 | 手机号 |
| avatar | string | 否 | 头像URL |
| is_active | boolean | 否 | 是否激活 |

**权限约束**：
- `admin` 角色不能修改 `admin` 或 `super_admin` 用户
- 只有 `super_admin` 可以设置 `super_admin` 角色

**响应示例**（HTTP 200）：返回完整的用户对象（同 2.1）

---

### 2.4 删除用户

```
DELETE /api/admin/users/{id}/
```

**功能**：删除指定用户账号

**权限**：admin / super_admin

**路径参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | integer | 是 | 用户ID |

**权限约束**：
- 不能删除自己
- `admin` 角色只能删除 `user` 角色用户

**响应示例**（HTTP 200）：

```json
{
  "detail": "用户删除成功"
}
```

**错误响应**（HTTP 403）：

```json
{
  "detail": "不能删除自己"
}
```

## 三、公共说明

### 3.1 错误响应格式

```json
{
  "detail": "错误描述信息"
}
```

### 3.2 常见 HTTP 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 201 | 创建成功 |
| 204 | 删除成功（无响应体） |
| 400 | 请求参数错误 |
| 401 | 未认证（Token 无效或过期） |
| 403 | 无权限访问 |
| 404 | 资源不存在 |

### 3.3 分页说明

当前接口暂未实现分页，如数据量较大，后续可能会添加 `page` / `page_size` 参数。

## 四、前端调用示例

### JavaScript (fetch)

```javascript
// 获取会话列表
const response = await fetch('/api/chat/conversations/', {
  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  }
});
const conversations = await response.json();

// 新建用户
const newUser = await fetch('/api/admin/users/', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    username: 'testuser',
    email: 'test@example.com',
    password: 'Password123!',
    password_confirm: 'Password123!',
    role: 'user'
  })
});
```

### React (axios)

```javascript
import axios from 'axios';

const api = axios.create({
  baseURL: '/api',
  headers: { 'Authorization': `Bearer ${token}` }
});

// 获取用户列表
const users = await api.get('/admin/users/', { params: { role: 'user' } });

// 删除用户
await api.delete('/admin/users/10/');
```
