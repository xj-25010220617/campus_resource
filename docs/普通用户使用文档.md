# 校园虚拟资源管理平台普通用户使用文档

## 一、适用对象

本手册适用于普通用户。普通用户主要使用智能问答、历史会话和常见问题功能。

普通用户登录后，左侧主要菜单包括：

- 智能问答；
- 常见问题。

普通用户不能进入知识库管理、FAQ 管理、账号管理、部门管理和日志管理页面。

## 二、登录系统

1. 打开系统首页。
2. 输入账号和密码。
3. 点击“登录”。
4. 登录成功后进入“智能问答”。

未登录时也可以浏览首页，但使用完整问答和历史会话功能时需要登录。如果访问了没有权限的页面，系统会自动返回智能问答页面。

## 三、智能问答

### 3.1 直接提问

1. 进入“智能问答”。
2. 在页面下方的“输入你的问题…”输入问题。
3. 点击输入框右侧的发送按钮，或按 Enter 键发送。
4. 等待系统生成回答。
5. 阅读回答、参考资料、推荐追问和相关图片。

提问越具体，越容易得到有帮助的回答。例如：

- “图书馆周末几点开放？”
- “如何办理校园网？”
- “奖学金申请需要满足哪些条件？”
- “如何查找学习资料？”

### 3.2 使用推荐问题

在没有开始对话时，页面会显示一些推荐问题按钮。点击问题按钮，系统会自动将该问题发送给 AI。

如果推荐问题加载失败，可以点击“重试”，也可以直接在输入框中输入问题。

### 3.3 等待回答和取消回答

回答生成时：

- 页面会显示“正在回答…”；
- 输入框会显示“AI 正在回复…”；
- 输入框暂时不能继续发送新问题；
- 发送按钮会变为取消按钮。

如果等待时间过长，可以点击取消按钮停止本次回答，然后重新提问。

### 3.4 继续追问

回答完成后，如果下方出现推荐问题，点击推荐问题即可继续提问。也可以直接在输入框输入新的问题。

继续追问时，系统会结合当前对话内容理解问题。需要查询完全不同的主题时，建议点击“新建对话”。

### 3.5 查看参考资料

回答下方可能显示参考资料、相关图片或资料摘要。阅读参考资料可以帮助判断回答是否可靠。

AI 回答仅供参考。涉及以下内容时，应以学校正式通知或相关部门的确认结果为准：

- 成绩和考试；
- 费用和缴费；
- 处分和身份；
- 正式通知；
- 学校规章制度；
- 需要办理的重要业务。

## 四、语音输入

问答输入框右侧有麦克风按钮，可以使用语音提问。

操作步骤：

1. 点击麦克风按钮。
2. 对着设备清晰说出问题。
3. 说完后再次点击麦克风按钮，或等待识别结束。
4. 检查识别出的文字。
5. 系统会根据识别结果发送问题并生成回答。

使用语音时请注意：

- 允许浏览器使用麦克风；
- 尽量在安静环境中录音；
- 说话清晰、语速适中；
- 识别错误时，可以改用文字输入；
- 如果提示语音请求失败，请检查麦克风、浏览器权限和网络。

## 五、会话管理

### 5.1 新建对话

点击左侧“新建对话”，可以开始一个新的问答主题。

建议按照不同主题分别建立对话，例如把“校园网问题”和“图书馆问题”分开，方便以后查找。

### 5.2 查看历史对话

左侧会话列表会显示历史对话。点击某个对话即可查看其中的问答内容，并继续提问。

### 5.3 搜索对话

1. 点击左侧会话区域中的搜索功能。
2. 输入对话标题或相关内容。
3. 在结果中点击需要查看的对话。

### 5.4 重命名对话

1. 将鼠标移动到历史对话上。
2. 点击出现的编辑按钮。
3. 输入新的对话名称。
4. 按 Enter 确认。
5. 不需要修改时，点击其他空白区域取消。

### 5.5 删除对话

1. 将鼠标移动到需要删除的历史对话上。
2. 点击删除按钮。
3. 在“确定删除这个对话吗？”提示窗口中确认。

删除后通常不能恢复，请确认不再需要其中的问答内容。

## 六、评价 AI 回答

回答下方通常有评价按钮：

- 点赞：表示回答有帮助；
- 点踩：表示回答不准确、不完整或没有解决问题。

评价只针对当前账号自己的问答。已经评价后，可以根据页面提示取消或更改评价。

## 七、常见问题

### 7.1 查看 FAQ

1. 点击左侧“常见问题”。
2. 浏览问题列表。
3. 点击问题卡片展开答案。
4. 再次点击可以收起答案。

普通用户只能查看已经发布的 FAQ，不能查看草稿和已驳回内容。

### 7.2 搜索问题

1. 在“搜索问题”输入框中输入关键词。
2. 点击搜索按钮，或按 Enter 键。
3. 查看搜索结果。
4. 点击“重置”清除搜索条件。

建议使用问题中的关键词搜索，例如“选课”“奖学金”“校园网”“图书馆”等。

### 7.3 按分类查看

在 FAQ 页面选择分类标签，可以只查看某一类常见问题。选择标签后，点击具体问题即可展开答案。

如果 FAQ 中没有找到答案，可以返回“智能问答”继续提问。

## 八、账号菜单

点击页面左侧底部的账号区域，可以使用：

- 个人中心；
- 退出登录。

使用公共电脑时，完成操作后务必点击“退出登录”。

## 九、普通用户不能使用的功能

普通用户不能：

- 上传和维护知识库资料；
- 编辑或删除其他人的文档；
- 管理 FAQ；
- 发布或驳回 FAQ；
- 管理其他用户账号；
- 管理学院和部门；
- 查看上传、查询、登录和操作日志；
- 查看管理员专用的完整资料引用信息。

## 十、常见提示

| 提示 | 处理方法 |
|---|---|
| 请先登录 | 登录后再使用问答或历史会话 |
| AI 回复超时 | 点击取消后重新提问，或稍后再试 |
| 回答生成失败 | 检查网络后重新发送问题 |
| 暂无推荐问题 | 直接在输入框输入问题 |
| 热点问题加载失败 | 点击“重试” |
| 没有找到相关资料 | 换用更具体的关键词，或补充问题背景 |
| 语音识别失败 | 检查麦克风权限，或改用文字输入 |
| 语音请求失败 | 检查网络和设备麦克风 |
| 没有权限访问页面 | 当前账号没有该功能，请返回智能问答 |
| FAQ 暂无数据 | 清除搜索条件或更换关键词 |

## 十一、提问建议

- 尽量使用完整句子；
- 说明时间、地点、学院或业务名称；
- 一个问题尽量只描述一个主题；
- 对回答有疑问时，可以继续追问“依据是什么”或“适用范围是什么”；
- 重要事项不要只依赖 AI 回答，应核对学校正式资料。
