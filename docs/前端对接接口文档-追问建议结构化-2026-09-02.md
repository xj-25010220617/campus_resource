# 前端对接接口文档 — 追问建议结构化（2026-09-02）

> **日期**：2026-09-02
> **后端分支**：main
> **变更类型**：`suggested` SSE 事件结构变更（**前端需适配**）

---

## 〇、本次变更

| 接口 | 事件 | 变更 |
|------|------|------|
| `POST /api/chat/ask/`（及网页分析 / 联网搜索 / 内建知识库等旁路） | `suggested` | `data` 由纯字符串数组改为对象数组 |

**目的**：引导句（「您查询了学校在校生人数，需要我为您分别整理各学院的学生分布情况吗？」）用于展示；用户点击后发送的是去掉套话的**干净问句**（「各学院的学生人数分别是多少？」），避免把引导语原封不动当成下一轮提问。

---

## 一、变更前 → 变更后

**变更前**：

```json
["您查询了学校在校生人数，需要我为您分别整理各学院的学生分布情况吗？", "想了解专任教师的具体构成吗？...", "..."]
```

**变更后**：

```json
[
  {
    "display": "您查询了学校在校生人数，需要我为您分别整理各学院的学生分布情况吗？",
    "question": "各学院的学生人数分别是多少？"
  },
  {
    "display": "想了解专任教师的具体构成吗？比如高级职称和硕博士比例？",
    "question": "专任教师中高级职称和硕博士各占多少？"
  },
  {
    "display": "需要我帮您对比近几年在校生人数的变化趋势吗？",
    "question": "近几年在校生人数有什么变化趋势？"
  }
]
```

字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| `display` | string | 引导式问句，**前端展示用**（按钮文案） |
| `question` | string | 干净问句，**用户点击后实际发送**的提问内容 |

> 兜底说明：极少数情况下 LLM 可能返回纯字符串（旧格式），后端已归一化为 `{"display": 同字符串, "question": 同字符串}`，前端按对象处理即可，不会拿到裸字符串。

---

## 二、前端适配

渲染时用 `display`，点击发送时用 `question`：

```js
// SSE 收到 suggested 事件
onSuggested: (data) => {
  suggestions = (data || []).map(s => ({
    label: s.display,      // 按钮显示
    value: s.question,     // 点击后填入输入框/发送
  }));
}

// 点击引导按钮
function onSuggestionClick(s) {
  sendQuestion(s.value);   // 发送 question，而非 display
}
```

React 示例：

```jsx
{suggestions.map((s, i) => (
  <button key={i} onClick={() => sendQuestion(s.question)}>
    {s.display}
  </button>
))}
```
