## 五、API 变更

### 5.1 新增接口（仅 super_admin）

#### 列表 + 详情

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/admin/logs/upload/` | 上传日志列表 |
| GET | `/api/admin/logs/upload/<int:pk>/` | 上传日志详情 |
| GET | `/api/admin/logs/query/` | 查询日志列表 |
| GET | `/api/admin/logs/query/<int:pk>/` | 查询日志详情 |
| GET | `/api/admin/logs/sensitive/` | 敏感内容日志列表 |
| GET | `/api/admin/logs/sensitive/<int:pk>/` | 敏感内容日志详情 |
| GET | `/api/admin/logs/login/` | 登录日志列表 |
| GET | `/api/admin/logs/login/<int:pk>/` | 登录日志详情 |
| GET | `/api/admin/logs/operation/` | 操作日志列表 |
| GET | `/api/admin/logs/operation/<int:pk>/` | 操作日志详情 |

#### 统计

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/admin/logs/upload/stats/` | 上传统计（total/today/week/month + by_status/file_type/college + total_size） |
| GET | `/api/admin/logs/query/stats/` | 查询统计（avg_hit / avg_ms / like_rate / by_feedback） |
| GET | `/api/admin/logs/login/stats/` | 登录统计（success/fail + by_type/by_hour） |
| GET | `/api/admin/logs/operation/stats/` | 操作统计（by_action/by_target_type/top_operators） |

#### Dashboard 聚合

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/admin/logs/dashboard/?period=day|week|month` | 5 类日志综合聚合（5 个 block，各块 try/except 隔离失败） |

### 5.2 接口注释（强制 CONVENTIONS §4）

所有新增视图均按规范书写中文文档字符串，包含功能 / 参数 / 返回值。例如：

```python
class AdminUploadLogListView(generics.ListAPIView):
    """上传日志列表 - 超管

    GET /api/admin/logs/upload/
    过滤：user_id / status / college_id / department_id / file_type /
          date_from (YYYY-MM-DD or ISO) / date_to / keyword (file_name)
    返回：分页的上传日志列表
    """
```

### 5.3 权限

- 5 类日志接口 + 4 个 stats 接口 + dashboard：`permissions.IsAuthenticated + IsSuperAdmin`
- 既有用户管理接口（UserAdminViewSet 等）：保持 `IsAuthenticated + IsAnyAdmin`，不收紧

### 5.4 请求示例

```bash
# 1. 上传统计
curl -H "Authorization: Bearer <super_admin_token>" \
  http://127.0.0.1:8000/api/admin/logs/upload/stats/

# 2. 操作日志
curl -H "Authorization: Bearer <super_admin_token>" \
  "http://127.0.0.1:8000/api/admin/logs/operation/?action=delete&date_from=2026-07-01"

# 3. Dashboard
curl -H "Authorization: Bearer <super_admin_token>" \
  "http://127.0.0.1:8000/api/admin/logs/dashboard/?period=week"
```

## 九、执行步骤（用户手动）

1. 在远程 MySQL 上跑两条建表 SQL（见 `database-changes/admin_login_log.md` 和 `admin_operation_log.md`）
2. `SHOW TABLES LIKE 'admin_%';` 验证两张表存在
3. `DESC admin_login_log;` / `DESC admin_operation_log;` 验证字段对齐
4. 启动后端 `python manage.py runserver`
5. 用 super_admin token 调任一日志接口，期望 200
6. 用学院管理员 / 学生 token 调任一日志接口，期望 403
7. 走一遍 JWT 登录 + SSO Mock 登录，检查 `admin_login_log` 新增行
8. 走一遍用户管理 CRUD（create/update/delete/reset_password），检查 `admin_operation_log` 新增行
