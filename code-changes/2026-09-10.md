## 二、新增代码范围

### 2.1 FileUploadView 空文件短路（backend/apps/knowledge/views.py）

| 文件 | 说明 |
|------|------|
| `backend/apps/knowledge/views.py` | 🔧 在 `needs_ai` 判断前新增 `is_empty_file` 检测：**0 字节**，或**文本类（`TEXT_EXTRACTABLE_TYPES`，直接 decode 文件字节、不依赖解析库）提取不到任何文本内容**。空文件时直接 `title='空文件'`、`description=''`、`raw_keywords=[]`、`visibility=data['visibility']`，**跳过 AI 调用**；非空文件才进入原有的 `needs_ai` → `_ai_classify` 流程。⚠️ 首版曾把**文档类（`DOCUMENT_EXTRACTABLE_TYPES`）**也纳入判空，因 PDF/PPT/Excel 解析库缺失时 `extracted_text` 恒为空，导致**有内容的正常文档被误判为「空文件」**，已修正为仅对文本类判空 |

关键片段：

```python
is_empty_file = (
    len(file_bytes) == 0
    or (
        ext in self.TEXT_EXTRACTABLE_TYPES
        and not extracted_text.strip()
    )
)
if is_empty_file:
    # 空文件跳过 AI，标题固定「空文件」，描述/关键词留空，分类保留真实格式
    title = '空文件'
    description = ''
    raw_keywords = []
    visibility = data['visibility']
```
