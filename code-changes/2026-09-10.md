is_empty_file = (
    len(file_bytes) == 0
    or (
        (ext in self.TEXT_EXTRACTABLE_TYPES or ext in self.DOCUMENT_EXTRACTABLE_TYPES)
        and not extracted_text.strip()
    )
)
if is_empty_file:
    # 空文件跳过 AI，标题固定「空文件」，描述/关键词留空，分类保留真实格式
    title = '空文件'
    description = ''
    raw_keywords = []

| `ModerationAttempt` | 与 `ContentModeration` **一对多**的**不可变**审核历史；`unique(moderation, attempt_seq)` |

> 继续叠加会再次造成语义混乱，且审核有独立生命周期（历史 / 重试 / 租约）。
> `KnowledgeDoc.oss_key` 的**现有语义不变**，本阶段不改动。

#### 2.3 OSS quarantine / promotion 原语 (`backend/utils/oss.py`)

| 内容 | 说明 |
|------|------|
| `QUARANTINE_KEY_PREFIX` = `quarantine/` | 隔离区顶层前缀，与 `knowledge/` **平级**（不是 `knowledge/quarantine/`） |
| `OFFICIAL_KEY_PREFIX` = `knowledge/` | 正式区前缀（与 `moderation.INDEXABLE_OSS_KEY_PREFIX` 一致，有测试守护） |
| `OSSOperationError` | 显式异常。安全关键路径上不做"失败即降级返回 None"的处理 |
| `OSSClient.copy_object()` | **服务端**复制（不下载到本机），复制后 HEAD 确认目标对象存在 |
| `OSSClient.iter_object_chunks()` | **流式**读取，逐块产出，带 `chunk_size` / `max_bytes` 硬限制，超限抛错而非静默截断 |
| `OSSClient.promote_object()` | `quarantine/ → knowledge/` 的 copy + HEAD 大小校验；**硬编码前缀限制**，**不删除源对象**，**不修改任何数据库记录** |
