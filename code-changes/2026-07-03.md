## 五、处理流程

```
用户提问 → 序列化器 → check_sensitive()
    ├─ 命中 → SensitiveLog 记录 → 400 + SENSITIVE_CONTENT + 分类拒绝话术
    └─ 未命中 → RAG 检索 + AI 回答
```

## 六、拒绝话术分级

| 命中类型 | 拒绝话术要点 |
|------|------|
| `classified` | 涉及内部保密信息，联系职能部门 |
| `privacy` | 包含个人隐私，不处理 |
| `structural` | 系统内部数据/密钥 |
| `bypass` | 检测到绕过低图 |
| `forbidden_generation` | 不支持生成涉密载体 |
| `forbidden_access` | 获取保密资料不被允许 |

## 七、SensitiveLog 模型

| 字段 | 类型 | 说明 |
|------|------|------|
| `user` | FK→User, SET_NULL | 触发用户 |
| `question` | TextField | 问题原文 |
| `matched_rules` | JSONField | 命中规则列表 [{rule, desc, type, category}] |
| `matched_texts` | JSONField | 命中的敏感文本片段 |
| `refuse_message` | TextField | 拒绝回复内容 |
| `created_at` | DateTimeField | 触发时间 |
