## 六、角色权限矩阵（互斥归属语义）

| 角色 | 管理用户范围 | 管理资源范围 | 看可见性文档范围 |
|------|-------------|-------------|------------------|
| `super_admin` | 全部（不含同级） | 全部 | 全部 |
| `admin`（兼容旧） | 本学院 `user` | 本学院资源（`college_id=本院`、`department_id IS NULL`） | 公开 + 本院私有 + 自己私有 |
| `college_admin` | 本学院 `user` | 本学院资源（`college_id=本院`、`department_id IS NULL`） | 公开 + 本院私有 + 自己私有 |
| `dept_admin` | 本部门所有用户 | 本部门资源（`department_id=本部门`、`college_id IS NULL`） | 公开 + 本部门员工上传 |
| `user` | 无 | 无 | 公开 + 自己私有 |

## 七、设计说明

**互斥归属**：资源只能属于学院（`college_id`）或部门（`department_id`）中的一个。  
**灵活上传**：部门管理员上传资源时，**不强制锁定**其本人归属部门，而是要求管理员手动从下拉框选择 `college_id` / `department_id` / `discipline_id`，允许跨学院/跨部门上传跨归属的公共资源。  
**历史兼容**：保留 `admin` 角色值以兼容旧数据，行为与 `college_admin` 等价。
