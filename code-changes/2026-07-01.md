## 五、API 变更

### 5.1 新增接口

| 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|
| `POST` | `/api/chat/ask/` | 提问（SSE 流式返回，含硬过滤检索） | 登录用户 |
| `POST` | `/api/chat/feedback/` | 对上一次回答评价（1=赞 / 0=踩） | 登录用户 |
| `GET` | `/api/chat/conversations/` | 获取当前用户的会话列表 | 登录用户 |
| `GET` | `/api/chat/conversations/<id>/` | 获取某会话的完整消息列表 | 登录用户（仅自己） |

### 5.2 接口注释（按 CONVENTIONS 强制规则）

```python
class AskView(APIView):
    """
    AI 问答接口（三层检索升级版）

    POST /api/chat/ask/
    功能：接收用户提问 → LLM 解析为硬过滤 → SQL 缩范围 → 向量+关键词双路召回 → 权限校验 → 生成回答
    参数：
        - conversation_id (int, optional): 会话 ID（不传则新建）
        - question (str, required): 用户提问
    返回：
        - SSE 流式响应（text/event-stream）
        - 首条事件包含 message_id，用于反馈
    """


class FeedbackView(APIView):
    """
    问答反馈接口

    POST /api/chat/feedback/
    功能：用户对上一条 AI 回答点赞/点踩，写入 query_log
    参数：
        - message_id (int, required): 消息 ID
        - feedback (int, required): 1=赞 / 0=踩
    返回：
        - 200: {"detail": "反馈已记录"}
    """
```

### 5.3 请求示例

```bash
# 1. 提问
curl -X POST http://127.0.0.1:8000/api/chat/ask/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "计算机系大三下学期的操作系统复习资料",
    "conversation_id": null
  }'

# 2. 反馈
curl -X POST http://127.0.0.1:8000/api/chat/feedback/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message_id": 1234,
    "feedback": 1
  }'
```
