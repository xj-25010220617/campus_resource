| 方法 | 路径 | 功能 | 权限 |

### 5.2 接口注释（按 CONVENTIONS 强制规则）

```python
class AskView(APIView):
    """
    AI 问答接口（三层检索升级版）

    POST /api/chat/ask/
    功能：接收用户提问 → LLM 解析为硬过滤 → SQL 缩范围 → 向量+关键词双路召回 → 权限校验 → 生成回答
    参数：
        - conversation_id (int, optional): 会话 ID（不传则新建）
        - question (str, required): 用户提问
    返回：
        - SSE 流式响应（text/event-stream）
        - 首条事件包含 message_id，用于反馈
    """


class FeedbackView(APIView):
    """
    问答反馈接口

    POST /api/chat/feedback/
    功能：用户对上一条 AI 回答点赞/点踩，写入 query_log
    参数：
        - message_id (int, required): 消息 ID
        - feedback (int, required): 1=赞 / 0=踩
    返回：
        - 200: {"detail": "反馈已记录"}
    """
```

| **视图类** | `UploadCallbackView(APIView)` |
| **权限** | `IsAuthenticated` + `IsAdminOrSuperAdmin` |
| **请求序列化器** | `UploadCallbackSerializer`（7 必填 + 3 选填） |

### 2.3 业务逻辑流程

1. 权限校验 → `request.user.role in ('admin', 'super_admin')`
2. 参数校验 → `UploadCallbackSerializer`
3. oss_key 安全校验 → `_validate_oss_key()`
   - 拒绝 `..`（路径穿越）
   - 拒绝 `/` 开头（绝对路径）
   - 拒绝非 `knowledge/` 前缀
4. MD5 再次去重 → `oss_client.check_duplicate(md5)`
   - 命中 → 返回 `{id, status, duplicate: true}`
5. 创建 KnowledgeDoc 记录：
   - `source_type='upload'`, `status='uploaded'`, `uploader=request.user`
   - `college_id` 优先取请求参数，未传则取上传者学院
6. 返回 `{id: new_doc.id, status: 'uploaded'}`
7. Celery 异步索引待集成（TODO）
