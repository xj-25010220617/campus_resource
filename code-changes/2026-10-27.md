# 代码修改记录 — 2026-10-27

> **需求**：标签功能此前只在「上传文档」时体现，上传后就无处使用。本需求把标签铺到浏览/筛选/管理链路，
>   让标签真正兑现「浏览/筛选/聚合」的定位：
>   1. 文档列表卡片显示标签徽章（列表序列化器加轻量 `tags` 字段）；
>   2. 文档列表支持按标签筛选（`?tag_id=` / `?tag=`）；
>   3. 标签词表带文档数（`GET /tags/` 每项加 `doc_count`，按当前用户可浏览范围计算）；
>   4. 详情页标签跳转（后端已具备，前端复用第 2 条筛选即可，无后端改动）；
>   5. 标签词表管理接口（重命名 / 合并 / 软删，仅超管）。
>   无数据库结构变更（复用 `tag` / `doc_tag` 表）。
> **修改人**：userName
