# 代码修改记录 — 2026-09-27

> **需求**：智能问答无法展示图片。用户提问「给我一个校园活动宣传海报」时机器人回答找不到图片。
>   诊断确认：图片文档（`file_type='image'`）共 9 篇，全部 `status='failed'`（图片没有文本解析器，
>   走文本索引流程抽不出正文，即使视觉模型已生成完整 title/description，索引任务仍判失败），
>   而 `retrieve_images()` 检索时按 `status='indexed'` 过滤，与其函数 docstring「不按 status='indexed' 过滤」
>   直接矛盾，导致 9 张图被一刀切光、后端不下发 `images` 事件、前端无图可展示。
>   本需求去掉 `retrieve_images()` 的 status 过滤，图片检索仅按 file_type + 权限过滤，靠标题/描述关键词召回。
>   无数据库结构变更。
> **修改人**：Fressia-zzt

## 六、数据清理（可选，服务器执行一次）

把 file_type 为图片且 `status='failed'`、有 title/description 的文档置为 `indexed`，让图片状态干净、
避免其他按 `status='indexed'` 过滤的逻辑遗漏图片。**本修复不依赖此脚本**（已去掉 status 过滤），属可选清理：

```bash
python manage.py shell <<'EOF'
from apps.knowledge.models import KnowledgeDoc
from apps.knowledge.serializers import IMAGE_FILE_TYPES
types = ['image'] + list(IMAGE_FILE_TYPES)
qs = KnowledgeDoc.objects.filter(file_type__in=types, status='failed')
fixed = 0
for d in qs:
    if d.title or d.description:
        d.status = 'indexed'
        d.index_error = ''
        d.save(update_fields=['status', 'index_error', 'updated_at'])
        fixed += 1
print('置为 indexed 的图片数:', fixed)
EOF
```
