## 五、API 变更

### 5.1 扩展接口

#### Dashboard 聚合接口响应新增字段

| 方法 | 路径 | 变更 |
|------|------|------|
| GET | `/api/admin/logs/dashboard/` | 响应顶层新增 `totals` 字段 |

**新增字段（与 `blocks` 同级，受 `AllowAny` 鉴权策略约束，不受 `period` 控制）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `totals.users` | integer | 全平台 `User` 总数（含 super_admin / college_admin / dept_admin / user 等所有角色） |
| `totals.upload_total_size` | integer | 全平台 `UploadLog.file_size` 累计字节数（非"今日/本周/本月"区间值） |

**响应示例（节选）：**

```json
{
  "period": "day",
  "start_at": "2026-07-09T00:00:00+08:00",
  "end_at":   "2026-07-09T09:30:00+08:00",
  "totals": {
    "users": 1234,
    "upload_total_size": 524288000
  },
  "blocks": { "upload": { "...", "total_size": 8388608 }, "...": "..." }
}
```

### 5.2 向后兼容

- `totals` 是新增顶层字段，旧前端忽略未知字段不报错
- `blocks.*` 5 个块结构零变更
- `permission_classes` 维持 `permissions.AllowAny`，不引入 401 / 403
- 不新增 URL、不动路由

## 七、执行步骤（用户手动）

1. 启动后端 `python manage.py runserver`
2. `curl http://127.0.0.1:8000/api/admin/logs/dashboard/` 应返回 200，响应顶层含 `totals.users` 与 `totals.upload_total_size`
3. `python manage.py check` 无错误
4. 手工对比 `SELECT COUNT(*) FROM accounts_user;` 与 `SELECT SUM(file_size) FROM resources_uploadlog;` 应与 `totals` 字段值一致
