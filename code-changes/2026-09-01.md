## 一、删除代码范围

| `backend/utils/sse.py` | 删除 `_format_sse` 中 `elif not isinstance(data, str): data = str(data)` 分支（list 走 `str()` 会产生单引号 Python repr，如 `['问题1','问题2']`，非法 JSON，前端 `JSON.parse` 失败） |
