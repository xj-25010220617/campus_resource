## 八、补充修改（同一需求：追问覆盖全部问答路径）

> 排查发现 `AskView` 共有 **5 条独立 SSE 流式路径**，但仅有主 RAG 路径（普通知识问答）生成了 `suggested` 追问事件；其余 4 条路径在 AI 答完后直接 `done` 结束，导致「文件/资源/网页/搜索」类问题没有追问。

### 8.1 变更文件

| 文件 | 说明 |
|------|------|
| `backend/apps/chat/views.py` | 4 条非 RAG 路径补齐 `generate_suggested_questions` + `yield _format_sse('suggested', ...)`：① `_handle_data_query`（文件管理查询）② `_handle_web_query`（网页实时分析）③ `_fallback_to_knowledge`（内建知识库兜底）④ `_handle_search_query`（联网搜索） |

### 8.2 变更细节

- 各路径在流式输出结束后，将累积的 token 拼成 `full_answer`（`_handle_data_query` 已有，其余 3 条由 `yield` 逐字输出改为 `full_answer.append(token)` 后拼接）。
- 在 `done` 事件前插入：
  ```python
  suggested = rag.generate_suggested_questions(question, ''.join(full_answer))
  if suggested:
      yield _format_sse('suggested', suggested)
  ```
- `_handle_web_query` 仍遵循「不存储」语义：仅本地拼接 `full_answer` 用于生成追问，不回写 `content`。

### 8.3 数据库变更

无。未涉及表结构 / 字段 / 索引变更。

### 8.4 验证步骤

1. `python manage.py check` → 0 问题
2. 分别提问命中以下意图，观察 SSE 流末尾均出现 `event: suggested`：
   - 文件管理查询：如「我上传了多少个文件？」
   - 普通知识问答：如「成都东软学院有多少在校生？」
   - 联网搜索：如「成都东软学院招生就业」
   - 网页分析：如「https://www.nsu.edu.cn 有哪些栏目？」
3. `suggested` 的 `data` 为合法 JSON 数组（双引号）
