## 二、新增代码范围

### 2.1 时区修复（backend/utils/context.py）

| 文件 | 说明 |
|------|------|
| `backend/utils/context.py` | 🔧 `get_current_time_str()` 中 `t = now or timezone.now()` 之后新增 `t = timezone.localtime(t)`。根因：`USE_TZ=True` 时 `timezone.now()` 返回 **UTC**，直接 `strftime('%H:%M')` 输出 UTC 墙钟时间（比北京时间慢 8 小时）；`timezone.localtime()` 按 `TIME_ZONE=Asia/Shanghai` 转本地后再格式化 |
| `backend/utils/context.py` | 🔧 `get_daily_briefing()` 中 `doc_count=Max('id')` 改为 `Count('id')`（原「共 N 条」实为最大 id，计数错误）；`latest/earliest`（库中为 UTC）改用 `timezone.localtime()` 转本地时区后再取日期，避免跨天边界日期偏一天 |

关键片段：

```python
t = now or timezone.now()
# USE_TZ=True 时 timezone.now() 返回 UTC；直接 strftime 会输出 UTC 墙钟时间，
# 比北京时间（TIME_ZONE=Asia/Shanghai）慢 8 小时。必须先转成本地时区。
t = timezone.localtime(t)
date_str = t.strftime('%Y年%m月%d日')
```

### 2.2 纯时间问题检测（backend/utils/rag.py）

| 文件 | 说明 |
|------|------|
| `backend/utils/rag.py` | 🔧 新增 `_TIME_CORE_PATTERNS`（时间问句白名单）+ `_is_time_question(question)`：去标点、去「请问」前缀、去结尾语气词后**整句精确匹配**，命中才判定为纯时间问题。用精确匹配而非前缀匹配，避免误伤「图书馆现在几点关门」「现在几点钟有课」等复合问题 |
| `backend/utils/rag.py` | 🔧 `retrieve()` 入口新增：`if _is_time_question(question): return []`（纯时间问题跳过 RAG，由 `build_system_context()` 注入的当前时间直接回答） |

### 2.3 系统提示词修正（backend/utils/rag.py）

| 文件 | 说明 |
|------|------|
| `backend/utils/rag.py` | 🔧 `SYSTEM_PROMPT` 指令第 3 条改为：「只有当你确实引用了『外部检索资料』中的具体内容时，才在回答末尾列出参考文件名称；时间/日期/星期等问题请直接依据『当前时间』回答，不要列出参考文件；严禁把『当前时间』『每日简报』『学校内建知识库』『系统实时注入时间』等内部来源当作参考文件列出」 |

### 2.4 兜底路径守卫（backend/apps/chat/views.py）

| 文件 | 说明 |
|------|------|
| `backend/apps/chat/views.py`（`AskView.post`） | 🔧 联网搜索兜底条件由 `if not results:` 改为 `if not results and not rag._is_time_question(question):`，避免「现在时间是多少」被丢给学校官网搜索、污染参考 |
| `backend/apps/chat/views.py`（`VoiceAskView._stream_answer`） | 🔧 `find_pending_index_docs` 条件由 `if not hits:` 改为 `if not hits and not rag._is_time_question(question):`，避免纯时间问题触发「已找到相关知识库文件」提示 |
