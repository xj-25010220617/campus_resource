## 五、对外暴露的新能力

### 接口 1：手动触发 AI 日期提取

```
POST /api/knowledge/docs/{id}/extract-freshness/?async=true|false
Authorization: Bearer <jwt>
```

- 异步（默认）：返回 `202 {task_id, status, doc_id}`
- 同步（`?async=false`）：返回 `200 {freshness_date, confidence, source_excerpt, raw_response}`

权限：仅 `super_admin` / `admin` 可触发；`admin` 仅能触发自己上传的文档。

### 接口 2：上传时自动触发

`UploadCallbackView` 返回成功之前，自动调用 Celery 任务提取日期，写回 `freshness_date`。前端无感。

## 六、关键设计

1. **零阻塞主链路**：上传回调通过 `safe_delay` 触发 Celery；Celery 不可用时仅记日志，不影响上传。
2. **数据库零迁移**：复用已有字段。
3. **三入口殊途同归**：上传自动 / 手动异步 / 手动同步，最终都调用 `extract_freshness_for_doc(doc_id)`。
4. **LLM 严格约束**：Prompt 不允许猜测；未找到日期时返回 `null` + `confidence='none'`。
5. **日期硬校验**：限定 2000-2099 年范围 + 三种格式归一化（YYYY-MM-DD / YYYY/MM/DD / YYYY年M月D日）。
